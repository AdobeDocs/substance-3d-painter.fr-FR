# Modèles de sortie par défaut

Vous trouverez ci-dessous une liste de Modèles de sortie supplémentaires fournis par défaut.  Les Modèles de sortie par défaut peuvent être copiés et modifiés dans l&#39;onglet <b>Modèles de sortie</b> de la <b>fenêtre d&#39;exportation</b>.

>[!NOTE]
>
> D&#39;autres logiciels non répertoriés ici peuvent également être pris en charge (tels que **Octane**). Pour plus d&#39;informations, consultez l&#39;[écosystème et les modules externes](https://experienceleague.adobe.com/en/docs/substance-3d/ecosystem/home).

| *Paramètre prédéfini* | *Description* |
| --- | --- |
| <b> Amazon Lumberyard </b> | Nommez et emballez les textures à importer et à utiliser dans Amazon Lumberyard. |
| <b> Arnold (AiStandard) </b> | Préréglage pour Arnold (AiStandard shader). |
| <b> Arnold UDIM hérité (AiStandard)</b> | Paramètre prédéfini pour Arnold UDIM hérité (AiStandard). |
| <b>Blender (Principled BSDF)</b> | Préréglage pour Blender (Principled BSDF). |
| Corona </b> <b> | Préréglage pour le rendu Corona. |
| <b> CryEngine 3 </b> | Nommer et emballer les textures à importer et à utiliser dans Cry Engine 3. |
| <b> Dota 2 </b> | Préréglage pour le jeu Dota 2 (peut être utilisé avec le modèle associé). |
| Keyshot </b> <b> | Paramètre prédéfini pour le rendu des images clés. |
| <b>Keyshot 9+</b> | Paramètre prédéfini pour le rendu Keyshot à partir de la version 9. |
| <b> Lens Studio </b> | Paramètre prédéfini pour Lens Studio (pour créer des ressources pour Snapchat). |
| <b>Maxwell (Rugosité métallique)</b> | Paramètre prédéfini pour le rendu Maxwell à l’aide du workflow Rugosité métallique. |
| <b>Maxwell (brillance au Specular)</b> | Paramètre prédéfini pour le moteur de rendu Maxwell à l’aide du flux de travaux Lustre Specular. |
| <b> Mappages de maillage </b> | Exportez individuellement les emplacements de texture plaquée au filet cuits d’un ensemble de textures (exportés à la même résolution que pour l’ensemble de textures). |
| <b>Glossité du Specular non PBR</b> | Nommez et exportez des textures pour un workflow de brillance de Specular non PBR. |
| Rugosité métallique PBR <b></b> | Nommez et exportez les textures nécessaires à un flux de production PBR Métallique/Rugosité standard. |
| Rugosité métallique PBR <b> (groupes de dossiers ou de PSDS) </b> | Similaire à PBR MetalRough, mais crée un dossier supplémentaire. Ce paramètre prédéfini est principalement adapté pour être utilisé avec le format de fichier par PSD. |
| <b> Specular PBR brillant</b> | Nommez et exportez les textures nécessaires à un workflow PBR Specular/brillance normal. (Les textures sont converties à partir du flux de travail Couleur de base/Métallique). |
| <b> brillance Specular PBR (convertie de la rugosité métallique</b>) | Convertissez les couches de couleur de base, de métal et de rugosité pour qu’elles soient compatibles avec le workflow Specular/brillance. |
| <b> Redshift </b> | Préréglage pour le moteur de rendu Redshift. |
| <b>Renderman (pxrDisney)</b> | Paramètre prédéfini pour le moteur de rendu à l’aide des cartes métalliques et de rugosité. |
| <b>Renderman (pxrSurface)</b> | Paramètre prédéfini pour le rendu à l’aide des mappages Diffus et Specular. |
| <b>Roblox (MaterialVariant)</b> | Paramètre prédéfini pour Roblox utilisant l’Albédo sans prise en charge alpha. |
| <b>Roblox (SurfaceAppearance)</b> | Paramètre prédéfini pour Roblox utilisant Colormap avec couche alpha. |
| <b> Shade 3D </b> | Paramètre prédéfini pour Shade 3D. |
| <b>Spark AR Studio</b> | Préréglage pour Spark AR Studio. |
| <b>Pipeline de rendu Unity HD (norme métallique)</b> | Paramètre prédéfini pour le pipeline de rendu HD d’Unity à l’aide des cartes Métallique et Brillance. |
| <b>Pipeline de rendu Unity HD (Specular)</b> | Paramètre prédéfini pour le pipeline de rendu HD d’Unity avec une carte de specular ajoutée. |
| <b>Pipeline de rendu universel Unity (norme métallique)</b> | Paramètre prédéfini pour le pipeline de rendu universel d’Unity à l’aide de cartes métalliques et Smoothness. |
| <b>Pipeline de rendu universel Unity (Specular)</b> | Paramètre prédéfini pour le pipeline de rendu universel d’Unity avec des mappages de Specular et de Smoothness. |
| <b> Unreal Engine (Packed) </b> | Nommez et collez les textures à utiliser dans le moteur irréel avec la plus faible empreinte mémoire possible. |
| <b>Unreal Engine SSS (Packed)</b> | Nommez et collez les textures à utiliser dans le moteur irréel avec l&#39;empreinte mémoire la plus faible possible, en remplaçant la carte d&#39;opacité par la diffusion de sous-surface. |
| <b> Vray Next (Rugosité métallique)</b> | Paramètre prédéfini pour le rendu Vray à l’aide du workflow PBR. |
| <b>Suivant Vray (Lustre Specular)</b> | Paramètre prédéfini pour le rendu Vray à l’aide d’un workflow non PBR. |
| <b> Vray UDIM hérité (rugosité métallique)</b> | Paramètre prédéfini pour le rendu Vray (convention de nommage UDIM). |

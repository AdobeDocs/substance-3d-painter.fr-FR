# Modèles de sortie par défaut

Vous trouverez ci-dessous une liste de Modèles de sortie supplémentaires fournis par défaut.  Les Modèles de sortie par défaut peuvent être copiés et modifiés dans l&#39;onglet <b>Modèles de sortie</b> de la <b>fenêtre d&#39;exportation</b>.

>[!NOTE]
>
> D&#39;autres logiciels non répertoriés ici peuvent également être pris en charge (tels que **Octane**). Pour plus d&#39;informations, consultez l&#39;[écosystème et les modules externes](https://experienceleague.adobe.com/en/docs/substance-3d/ecosystem/home).

| *Paramètre prédéfini* | *Description* |
| --- | --- |
| <b> Amazon Lumberyard </b> | Nommez et emballez les textures à importer et à utiliser dans Amazon Lumberyard. |
| <b> Arnold (AiStandard) </b> | Préréglage pour Arnold (AiStandard shader). |
| <b> Arnold UDIM hérité (AiStandard)</b> | Paramètre prédéfini pour Arnold UDIM Legacy (AiStandard). |
| <b>Blender (Principled BSDF)</b> | Préréglage pour Blender (Principled BSDF). |
| Corona </b> <b> | Préréglage pour le rendu Corona. |
| <b> CryEngine 3 </b> | Nom et emballage des textures à importer et à utiliser dans le Moteur 3. |
| <b> Dota 2 </b> | Préréglage pour le jeu Dota 2 (peut être utilisé avec le modèle associé). |
| Keyshot </b> <b> | Paramètre prédéfini pour le rendu des images clés. |
| <b>Keyshot 9+</b> | Paramètre prédéfini pour le rendu Keyshot à partir de la version 9. |
| <b> Lens Studio </b> | Paramètre prédéfini pour Lens Studio (pour créer des ressources pour Snapchat). |
| <b>Maxwell (Métallique rugosité)</b> | Paramètre prédéfini pour le moteur de rendu Maxwell à l’aide du flux de travaux de Métallique rugosité. |
| <b>Maxwell (Specular Brillance)</b> | Paramètre prédéfini pour le moteur de rendu Maxwell à l’aide du workflow de Brillance Specular. |
| <b> Maps de maillage </b> | Exportez individuellement les emplacements de map de maillage bakés d&#39;un jeu de textures (exportés à la même résolution que pour le jeu de textures). |
| <b>Brillance de Specular non PBR</b> | Textures de nom et d’exportation pour un workflow de Brillance de Specular non PBR. |
| métallique rugosité PBR <b></b> | Nommez et exportez les textures nécessaires pour un workflow PBR Métallique/de Rugosité de données standard. |
| métallique rugosité PBR <b> (groupes de dossiers ou de PSDS) </b> | Similaire à PBR MetalRough, mais crée un dossier supplémentaire. Ce paramètre prédéfini est principalement adapté pour être utilisé avec le format de fichier par PSD. |
| <b> Brillance Specular PBR</b> | Nommez et exportez les textures nécessaires pour un workflow PBR de Specular/Brillance standard. (Les textures sont converties à partir du flux de travail BaseColor/Métallique). |
| brillance de Specular PBR <b> (convertie à partir de la Métallique rugosité </b>) | Convertissez les couches de couleur de base, Métalliques et de Rugosité pour qu’elles soient compatibles avec le workflow Specular/brillance. |
| <b> Redshift </b> | Préréglage pour le moteur de rendu Redshift. |
| <b>Renderman (pxrDisney)</b> | Paramètre prédéfini Rendu à l’aide des cartes Métallique et de rugosité. |
| <b>Renderman (pxrSurface)</b> | Paramètre prédéfini pour le rendu à l’aide de cartes Diffuse et Specular. |
| <b>Roblox (MaterialVariant)</b> | Paramètre prédéfini pour Roblox utilisant l’Albédo sans prise en charge alpha. |
| <b>Roblox (SurfaceAppearance)</b> | Préréglage pour Roblox utilisant Colormap avec canal Alpha. |
| <b> Shade 3D </b> | Paramètre prédéfini pour Shade 3D. |
| <b>Spark AR Studio</b> | Préréglage pour Spark AR Studio. |
| <b>Pipeline de rendu Unity HD (Métallique Standard)</b> | Paramètre prédéfini pour le pipeline de rendu HD d’Unity à l’aide de mappages Métallique et de Brillance. |
| <b>Pipeline de rendu Unity HD (Specular)</b> | Paramètre prédéfini pour le pipeline de rendu HD d’Unity avec une carte de specular ajoutée. |
| <b>Pipeline de rendu universel Unity (Métallique Standard)</b> | Paramètre prédéfini pour le pipeline de rendu universel d’Unity à l’aide de cartes Métalliques et par Smoothness. |
| <b>Pipeline de rendu universel Unity (Specular)</b> | Paramètre prédéfini pour le pipeline de rendu universel d’Unity avec des mappages de Specular et de Smoothness. |
| <b> Moteur irréel (compressé) </b> | Textures de nom et de pack à utiliser dans le Moteur irréel avec l’empreinte mémoire la plus faible possible. |
| <b>Système de stockage SSS de Moteur irréel (compressé)</b> | Nommez et composez les textures à utiliser dans le Moteur irréel avec l’empreinte mémoire la plus faible possible, en remplaçant map opacity par subsurface scattering. |
| <b> Vray Next (Métallique rugosité)</b> | Paramètre prédéfini pour le rendu Vray à l’aide du workflow PBR. |
| <b>Vray Next (Specular Brillance)</b> | Paramètre prédéfini pour le rendu Vray à l’aide d’un workflow non PBR. |
| <b> UDIM Vray hérité (Métallique rugosité)</b> | Paramètre prédéfini pour le rendu Vray (convention de dénomination UDIM). |

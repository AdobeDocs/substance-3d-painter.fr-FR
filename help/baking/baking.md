# Baking

![](../assets/banner-baking.jpg)

La cuisson fait référence à l&#39;action de **transfert d&#39;informations basées sur le maillage dans les textures**. Ces informations sont ensuite lues par des ombrages et/ou des filtres de Substance pour créer des effets avancés. Par exemple, les matériaux et masques dynamiques s’appuient sur la courbure au four et les cartes de normales, ainsi que d’autres informations de cuisson.

Dans Painter, la cuisson se fait via le mode de cuisson dédié. Ce mode est accessible via l&#39;icône dédiée (petit croissant dans la barre d&#39;outils contextuelle), en utilisant le [menu des modes](../interface/main-menu/mode-menu.md) ou avec le [raccourci clavier](../interface/settings/shortcuts.md).

Pour en savoir plus sur le processus de cuisson dans Painter, consultez les pages suivantes :

* [Paramètres de visualisation d’ancrage](baking-visualization-settings.md)

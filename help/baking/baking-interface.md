# Mode Baking

Le **mode Baking** permet d&#39;accéder à tous les outils et paramètres dont vous avez besoin pour créer de superbes bakes de haute qualité.

Pour accéder au **mode de Baking**, cliquez sur le bouton Croissant (baké) en haut à droite du Viewport. Vous pouvez également utiliser le [raccourci clavier ](../interface/settings/shortcuts.md)**F8** ou sélectionner le **Mode > Maps de maillage de Baking**

![](../assets/baking/mode_select_buttons.png)

Le mode Baking modifie la mise en page de l’interface utilisateur et rend différents panneaux disponibles spécifiquement pour les maps de maillage de baking.

## Interface

Par défaut, l&#39;interface Mode de Baking est divisée entre le [**Viewport**](../interface/viewport/viewport.md) et la zone du panneau.

### Viewport

Le [**Viewport**](../interface/viewport/viewport.md) se comporte de la même manière qu&#39;en **mode Peinture**. Vous pouvez naviguer avec les mêmes commandes et utiliser la **liste déroulante des canaux** pour modifier les canaux affichés.

Le **mode Baking** diffère du **mode Peinture** de deux façons :

* En haut à gauche du Viewport, vous trouverez le [**panneau des paramètres de visualisation du Baking**](baking-visualization-settings.md).
* En bas du viewport, vous trouverez des boutons pour **Baker** les maps de maillage actuellement sélectionnées ou revenir au **mode Peinture**.

### Panneaux Mode Baking

Il existe 4 panneaux exclusifs au mode Baking :

* [**bakers de Map de maillage**](../interface/baking-panels/mesh-map-bakers.md) : sélectionnez les maps de maillage bakées.
* [**Paramètres communs**](../interface/baking-panels/common-mesh-map-settings.md) : ajustez les paramètres de baking communs à toutes les maps de maillage.
* [**Panneau des paramètres de Map de maillage**](../interface/baking-panels/mesh-map-settings.md) : ajustez les paramètres de baking pour la map de maillage sélectionnée.
* [**Journal de Baking**](../interface/baking-panels/baking-log.md) : affichez les résultats des bakes et diagnostiquez les problèmes.

>[!NOTE]
>
> Voir [**Paramètres de Map de maillage**](mesh-map-settings.md) pour obtenir la liste complète des options disponibles dans les **Paramètres communs** et les **panneaux Paramètres de Map de maillage**.

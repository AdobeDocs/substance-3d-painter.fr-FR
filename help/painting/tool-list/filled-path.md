# Tracé doté d’un fond

![](../../assets/banner_filled_path.jpg)

L’outil de tracé rempli est un type d’outil de tracé qui permet de créer des formes sur la surface du modèle 3D remplies d’une couleur uniforme.

![](../../assets/filled_path_across_gaps.png)

L&#39;outil <b>Chemin rempli</b> est accessible à partir du menu Outils Chemin :

![](../../assets/filled_path_menu.png)

## Paramètres

Les paramètres de remplissage du tracé sont les suivants :

| Paramètre | Description |
| --- | --- |
| Opacité | Contrôlez l’opacité finale de la forme remplie. |

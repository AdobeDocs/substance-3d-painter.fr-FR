# Masque rapide

Le masquage rapide vous permet de masquer les parties de votre maillage sur lesquelles vous ne souhaitez pas effectuer de peinture.

* Appuyez sur **Y** pour passer en mode de modification par masque rapide. Cela vous permettra de mettre peinture à un masque temporaire.
* Appuyez à nouveau sur **U** pour revenir à votre outil et à votre peinture précédents sur ce masque.
* Appuyez sur **Y** pour réinitialiser/désactiver le masque.
* Appuyez sur **I** pour inverser le masque en mode de modification masque rapide.

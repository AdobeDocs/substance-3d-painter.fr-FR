# Masque rapide

Le masquage rapide vous permet de masquer les parties de votre filet sur lesquelles vous ne souhaitez pas peindre.

* Appuyez sur **Y** pour passer en mode de modification rapide du masque, cela vous permettra de peindre un masque temporaire.
* Appuyez à nouveau sur **U** pour revenir à l’outil précédent et peindre sur ce masque.
* Appuyez sur **Y** pour réinitialiser/désactiver le masque.
* Appuyez sur **I** pour inverser le masque en mode de modification rapide du masque.

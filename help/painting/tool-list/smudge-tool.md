# Outil Doigt

![](../../assets/image2018-6-12-18-14-12.png)

Nouveauté de Substance 3D Painter 2 : l’outil Doigt partage le même type de paramètres que l’[outil de peinture](https://support.allegorithmic.com/documentation/display/SPDOC/Paint+brush).

![](../../assets/smudge.gif)

## Utilisation

La façon la plus simple d’utiliser l’outil Doigt consiste à l’utiliser directement sur le contenu d’un calque de peinture, comme un outil de peinture ordinaire.

Une façon plus intelligente d’utiliser l’outil Doigt consiste à créer un calque de peinture et à définir toutes les couches du calque sur le mode de fusion « Transfert ». Cela permettra d&#39;étaler de manière non destructive toutes les couches situées sous la « couche d&#39;étalage ». Les calques ci-dessous restent intacts et toutes les modifications appliquées ultérieurement seront prises en compte par le calque Doigt.

# Préréglages

Un paramètre prédéfini est une configuration enregistrée d&#39;un [outil de peinture](../../painting/tool-list/tool-list.md). Ils peuvent être de trois types différents :

* **Paramètre prédéfini de pinceau** : enregistre les paramètres du pinceau (taille, flux, variation, pochoir et alpha).
* **Paramètre prédéfini de matériau** : enregistre les propriétés du matériau (canaux individuels et fichiers de Substance).
* **Paramètre prédéfini d&#39;outil** : enregistre les propriétés du pinceau et du Matériau, ainsi que le type d&#39;outil utilisé (Peinture, Doigt, Clone, etc.).

Les paramètres prédéfinis sont enregistrés sur le disque dans le dossier [Actifs](../../interface/assets/assets.md). Ils peuvent être copiés facilement sur les ordinateurs, car ils intègrent toutes les ressources qu&#39;ils utilisent.

Pour gérer vos paramètres prédéfinis, voir :

* [Création et enregistrement de paramètres prédéfinis](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/spdoc/creating-and-saving-a-preset-180191514.html)
* [Création de particules prédéfinies](../../painting/presets/creating-particles-pre/creating-particles-presets.md)
* [Photoshop Paramètre prédéfini de pinceau (ABR)](../../painting/presets/photoshop-brush-presets/photoshop-brush-presets-abr.md)

# Importation de pinceaux prédéfinis Photoshop

Cette page explique, étape par étape, comment importer un fichier ABR dans Substance 3D Painter.

1. <b>Ouvrez la fenêtre d&#39;importation des ressources.</b>

   La fenêtre Importer une ressource peut être ouverte de trois manières différentes :

   * Glissez-déposez le fichier ABR dans le panneau Actifs.
   * Utilisez <b>Fichier > Importer des ressources </b> dans le menu principal.
   * Utilisez le bouton <b>+ </b> dans le panneau Actifs.
1. <b>Ajoutez le fichier ABR à la fenêtre Importer des ressources.</b>

   Si vous n’avez pas fait glisser et déposé le fichier ABR dans la fenêtre Actifs pour ouvrir la fenêtre d’importation, il sera vide par défaut.

   Pour ajouter le fichier ABR, vous pouvez :

   * **Glissez-déposez** le fichier ABR dans la fenêtre.
   * Cliquez sur le bouton **Ajouter des ressources** pour sélectionner et charger le fichier ABR.

   >[!NOTE]
   >
   > ![](../../../assets/shelf-import-error.png)
   > 
   > Une icône d’avertissement peut apparaître en regard du fichier ABR en cas de problème. Tels que :
   > 
   > * Aucun paramètre prédéfini compatible trouvé. Pour plus d&#39;informations, consultez la liste [Compatibilité des paramètres de pinceau Photoshop](photoshop-brush-parameters-compatibility.md).
   > * Impossible de lire le fichier (par exemple, il est corrompu).
1. <b>Sélectionnez comment importer le fichier ABR.</b>

   Au bas de la fenêtre Importer des ressources, choisissez où charger le fichier ABR :

   * <b> Projet</b> : le fichier ABR sera chargé dans le projet actuellement ouvert. Les pinceaux ne seront disponibles que lorsque le projet en cours sera ouvert et sont joints au fichier de projet.
   * <b> Session</b> : le fichier ABR sera chargé en mémoire. Les pinceaux prédéfinis restent disponibles jusqu’à la fermeture de l’application.
   * <b> Bibliothèque</b> : le fichier ABR sera copié dans le tiroir du disque. Les pinceaux prédéfinis seront disponibles à chaque ouverture de Painter, pour tous les projets.

   ![](../../../assets/import-location.png)
1. <b>Accédez aux pinceaux prédéfinis à partir de l&#39;étagère.</b>

   ![](../../../assets/shelf-demo.png)

   Si aucun problème n’est survenu lors de l’importation des pinceaux prédéfinis, ils s’affichent dans la fenêtre [Actifs](../../../interface/assets/assets.md).

   >[!NOTE]
   >
   > Si un pinceau prédéfini est basé sur un bitmap, l’image qu’il utilise sera également disponible dans la section Alpha de la tablette sous le même nom que le pinceau prédéfini.

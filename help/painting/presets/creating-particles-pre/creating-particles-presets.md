# Création de paramètres prédéfinis de particules

Le système de particules qui permet de peindre des particules utilise **PopcornFX** qui s&#39;appuie sur des fichiers **.pkfx** pour définir les comportements.

Les brosses à particules sont composées de deux parties : l&#39;**émetteur** et le **récepteur**, qui sont enregistrés ensemble dans le paramètre prédéfini. L’application charge l’émetteur et remplace les événements de collision pour émettre le récepteur lors de la peinture.

Pour plus d’informations, consultez les pages dédiées :

* [Installation de l’éditeur de particules](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/spdoc/installation-of-the-editor-67403780.html)
* [Présentation de l’éditeur de particules](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/spdoc/overview-of-popcornfx-particle-editor-67796996.html)
* [Création D&#39;Un Script De Particule](creating-a-new-particle-script.md)

# Peinture

La peinture dans Substance 3D Painter peut être réalisée de nombreuses façons avec des outils manuels ou des actions automatiques.

Les outils de peinture manuelle sont accessibles directement via la barre d’outils (ou leur raccourci dédié). Lorsqu’un outil de peinture est sélectionné, ses propriétés s’affichent dans la fenêtre Propriétés.

Pour plus d’informations sur chaque outil, consultez leur page dédiée :

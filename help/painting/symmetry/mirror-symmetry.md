# Symétrie miroir

La symétrie miroir est une symétrie axiale qui peut être activée dans la barre d’outils contextuelle :

![](../../assets/symmetry-mirror.png)

## Utiliser le manipulateur pour positionner l&#39;axe de symétrie

Vous pouvez accéder aux paramètres d&#39;affichage de la symétrie à partir du bouton <b>Paramètres de symétrie</b> dans la barre d&#39;outils contextuelle en haut de la vue 3D. Sous les paramètres d’affichage, vous pouvez activer et personnaliser le manipulateur. Faites glisser les poignées de manipulation dans la vue 3D pour modifier la position de l’axe de symétrie.

![](../../assets/MirrorSymmetryManip.png)

## Paramètres de symétrie de miroir

![Capture d&#39;écran des paramètres de symétrie du miroir](../../assets/MirrorSymmetry-2.png){width="300px"}

| *Paramètre* | *Description* |
| --- | --- |
| <b>Axe</b> | Définit l&#39;axe de la scène utilisé pour effectuer la symétrie. |
| <b>Position de l&#39;axe</b> | Définit le décalage de l’axe dans le projet. Cette valeur peut être modifiée à l’aide des curseurs ou du manipulateur (voir ci-dessus). |
| <b>Afficher le plan</b> | Si cette option est activée, un plan transparent sera visible dans la clôture pour délimiter chaque côté de la symétrie en miroir. |
| <b>Afficher l&#39;intersection</b> | Si cette option est activée, une ligne est tracée sur le maillage dans la clôture pour délimiter chaque côté de la symétrie en miroir. |
| <b>Afficher le curseur</b> | Si cette option est activée, un deuxième curseur s’affiche de l’autre côté de la symétrie pour indiquer à quel moment la peinture sera effectuée. |
| <b>Masquer pendant la peinture</b> | Si cette option est activée, le deuxième curseur est masqué pendant que la peinture est en cours (jusqu’au relâchement du clic de la souris). |
| <b>Taille du manipulateur</b> | Définit la taille du Manipulateur dans la clôture. |

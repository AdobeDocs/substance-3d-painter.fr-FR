# Symétrie radiale

La symétrie radiale duplique les contours ou le contenu de calque de remplissage radialement autour d’un axe :

![](../../assets/radial-demo.gif)

## Utiliser le manipulateur pour positionner l’axe de symétrie

Vous pouvez accéder aux paramètres d&#39;affichage des Symétries à partir du <b>bouton des paramètres de Symétrie</b> dans la barre d&#39;outils contextuelle en haut de la vue 3D. Sous les paramètres d’affichage, vous pouvez activer et personnaliser le manipulateur. Faites glisser les poignées du manipulateur dans la vue 3D pour modifier la position de l’axe de symétrie.

![Capture d’écran du panneau des paramètres de symétrie radiale avec le manipulateur visible en viewport.](../../assets/RadialSymmetryManip.png){width="600px"}

## Paramètres de symétrie radiale

![Capture d&#39;écran de la section Symétrie du panneau Propriétés](../../assets/FillSymmetry_1.png){width="300px"}

| *Paramètre* | *Description* |
| --- | --- |
| <b>Axe</b> | Définit l&#39;axe de la scène utilisé pour effectuer la symétrie. |
| <b>Retourner la copie</b> | Inversez les copies en alternance sur l’axe U ou V. Cela est utile lors de l’utilisation de la symétrie sur du contenu dont le sens est le texte. |
| <b>Position de l&#39;Axe : X, Y, Z</b> | Définit le décalage de l’axe dans le projet. Cette valeur peut être modifiée avec les curseurs ou avec le Manipulateur (voir ci-dessus). |
| <b>Afficher l&#39;Axe</b> | Si cette option est activée, une ligne transparente apparaît dans le viewport pour représenter l’axe de symétrie. |
| <b>Afficher l&#39;intersection</b> | Si cette option est activée, un point est tracé sur le maillage dans le viewport pour indiquer où l’axe de symétrie croise le maillage. |
| <b>Afficher le curseur (outil Pinceau)</b> | Si cette option est activée, un deuxième curseur s’affiche de l’autre côté de la symétrie pour indiquer quand la peinture sera effectuée. |
| <b>Masquer pendant la peinture (outil Pinceau)</b> | Si cette option est activée, le deuxième curseur est masqué pendant que la peinture est en cours (jusqu’au relâchement du clic de la souris). |
| <b>Afficher le manipulateur de position de l&#39;Axe</b> | Activez/désactivez la visibilité du Manipulateur dans le viewport. |
| <b>Taille du Manipulateur</b> | Contrôle la taille du Manipulateur dans le viewport. |

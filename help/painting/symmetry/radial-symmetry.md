# Symétrie radiale

La symétrie radiale duplique le contenu des contours ou des calques de remplissage radialement autour d’un axe :

![](../../assets/radial-demo.gif)

## Utiliser le manipulateur pour positionner l&#39;axe de symétrie

Vous pouvez accéder aux paramètres d&#39;affichage de la symétrie à partir du bouton <b>Paramètres de symétrie</b> dans la barre d&#39;outils contextuelle en haut de la vue 3D. Sous les paramètres d’affichage, vous pouvez activer et personnaliser le manipulateur. Faites glisser les poignées de manipulation dans la vue 3D pour modifier la position de l’axe de symétrie.

![Capture d&#39;écran du panneau des paramètres de symétrie radiale avec le manipulateur visible dans la clôture.](../../assets/RadialSymmetryManip.png){width="600px"}

## Paramètres de symétrie radiale

![Capture d&#39;écran de la section Symétrie du panneau des propriétés](../../assets/FillSymmetry_1.png){width="300px"}

| *Paramètre* | *Description* |
| --- | --- |
| <b>Axe</b> | Définit l&#39;axe de la scène utilisé pour effectuer la symétrie. |
| <b>Retourner la copie</b> | Inversez les copies alternées sur l’axe U ou V. Cela est utile lors de l’utilisation de la symétrie sur un contenu dont le sens est le texte. |
| <b>Position de l&#39;axe : X, Y, Z</b> | Définit le décalage de l’axe dans le projet. Cette valeur peut être modifiée à l’aide des curseurs ou du manipulateur (voir ci-dessus). |
| <b>Afficher l&#39;axe</b> | Si cette option est activée, une ligne transparente représentant l&#39;axe de symétrie est visible dans la clôture. |
| <b>Afficher l&#39;intersection</b> | Si cette option est activée, un point est tracé sur le maillage dans la clôture pour indiquer où l&#39;axe de symétrie croise le maillage. |
| <b>Afficher le curseur (outil Pinceau)</b> | Si cette option est activée, un deuxième curseur s’affiche de l’autre côté de la symétrie pour indiquer à quel moment la peinture sera effectuée. |
| <b>Masquer pendant la peinture (outil Pinceau)</b> | Si cette option est activée, le deuxième curseur est masqué pendant que la peinture est en cours (jusqu’au relâchement du clic de la souris). |
| <b>Afficher le manipulateur de position de l&#39;axe</b> | Activez/désactivez la visibilité du manipulateur dans la clôture. |
| <b>Taille du manipulateur</b> | Définit la taille du Manipulateur dans la clôture. |

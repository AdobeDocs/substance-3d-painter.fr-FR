# Remplir les projections

![](../../assets/fill-properties.png)

Les effets de calque de remplissage et de remplissage projettent une texture directement sur le maillage en fonction d’un mode spécifique. Ce type de calque/d’effet évite de peinture manuelle des textures sur le modèle 3D. Les paramètres de la projection peuvent être modifiés via la fenêtre Propriétés.

Les propriétés sont divisées en deux catégories : **Propriétés de remplissage** et **Propriétés de Matériau**.

## Propriétés de remplissage

Les propriétés de remplissage déterminent la manière dont le Matériau est appliqué et/ou projeté sur le maillage. Le mode projection peut être modifié via la liste déroulante **Projection** dans la fenêtre [Propriétés](../../interface/properties.md).

Les modes de projection actuellement disponibles sont les suivants :

* [Fond (correspondance par Tuile UV)](fill-match-per-uv-tile.md)
* [UV projection](uv-projection.md)
* [Projection triplanaire](tri-planar-projection.md)
* [Projection planaire](planar-projection.md)
* [Projection sphérique](spherical-projection.md)
* [Projection cylindrique](cylindrical-projection.md)
* [Projection de la déformation](warp-projection.md)

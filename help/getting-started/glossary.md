# Glossaire

Substance 3D Painter est une application 3D qui repose sur de nombreuses techniques et mots-clés techniques qui peuvent être difficiles à comprendre au premier abord.\
Cette page répertorie les mots-clés les plus couramment utilisés dans l’application avec une brève explication des concepts sous-jacents.

| *Mot-Clé* | *Définition* |
| --- | --- |
| **Alignement** | L’alignement correspond à l’orientation du pinceau vers le filet 3D lors de la peinture. |
| **Alpha** | Un alpha est un masque qui peut être utilisé pour peindre des détails ou des formes complexes, par exemple un code-barres ou un logo. |
| **Cuire** | Fait référence à l’action de calculer les informations d’un maillage 3D et de les enregistrer dans une texture basée sur les informations UV d’un maillage. |
| **Nombre de bits par pixel** | Le nombre de bits par pixel correspond à la quantité d’informations pouvant être stockées dans une texture (par couleur). Plus le nombre est élevé, meilleure est la précision de l&#39;information. Cependant, les performances diminuent avec des nombres élevés lors des calculs. |
| **Pinceau** | Outil permettant de peindre un maillage. Un pinceau est défini par plusieurs paramètres qui contrôlent son comportement (tels que la taille et l’opacité). |
| **Appareil photo** | La caméra est l’objet qui permet de contrôler la position et la direction de l’endroit où vous regardez dans une clôture 3D ou 2D. |
| **Canal** | Une couche est une texture présentant un comportement spécifique. Certaines couches sont utilisées pour définir la couleur d’un matériau, d’autres pour contrôler la lumière de comportement sur une surface. |
| **Cloner** | L’outil Dupliquer est utilisé pour dupliquer une partie de la peinture/texture à un autre emplacement. |
| **Contenu/Masque** | Le contenu et le masque font référence aux deux propriétés principales d’un calque. Le contenu est la peinture réelle stockée dans les couches contenues dans un calque, tandis que le masque est utilisé pour afficher/masquer le contenu. Un masque noir est égal à un contenu invisible. |
| **Diffusion** | La diffusion est un moyen de générer des informations en dehors de l&#39;Îlot UV d&#39;un maillage. Elle fonctionne en faisant baver les derniers pixels près du bord d’un îlot UV, créant ainsi des couleurs floues. |
| **Dilatation/Remplissage** | Sur la même idée que la diffusion, la dilatation est un moyen de générer des informations en dehors de l&#39;Îlot UV en étendant les couleurs des pixels. |
| **Effet** | Élément qui peut être ajouté sur un calque, soit sur le contenu, soit sur le masque. Substance 3D Painter prend en charge différents types d’effets, tels que les filtres. |
| **Environnement** | Un environnement est une image utilisée pour calculer l’éclairage d’une scène. Il s’agit généralement d’une texture HDR qui représente une large gamme d’informations colorimétriques. |
| **Exporter** | L’exportation permet de générer des textures aplaties à partir de la peinture réalisée dans l’application. Les textures créées à partir de l’exportation peuvent être utilisées dans d’autres applications. |
| **Champ de vision** | Le FOV est l&#39;étendue du monde observable par la caméra. |
| **Remplir** | Le remplissage est une action (qui peut être un effet ou un calque) qui peut charger une couleur, une texture ou même un matériau sur l’ensemble du maillage 3D. |
| **Filtre** | Un filtre est un effet de Substance qui peut modifier les informations précédentes. Par exemple, un filtre de flou adoucit une image précédente. Les filtres peuvent également être plus complexes et modifier un matériau entier. |
| **Filtrage** | Le filtrage fait référence à la façon dont les textures sont affichées dans une clôture 3D. Les plus courants sont les pixels les plus proches (les pixels sont lus tels quels, donnant l’impression qu’une image est obstruée de près) et bilinéaires (les pixels sont interpolés, donnant l’impression qu’une image est floue de près). |
| **GPU** | Le GPU (processeur graphique) est la partie d’un ordinateur qui effectue des calculs rapides pour produire des images. |
| **Générateur** | Un générateur est une Substance qui génère de nouvelles informations/images, généralement en fonction de textures supplémentaires. Par exemple, certains générateurs de masques utilisent une texture cuite pour créer des masques complexes. |
| **Histogramme** | Un histogramme est une représentation graphique de la distribution des valeurs chromatiques. Il permet de visualiser l’équilibrage des couleurs dans une image entre les ombres, les tons moyens et les tons clairs. |
| **Iray** | Iray est un système de rendu de tracé de tracé créé par NVIDIA, utilisé pour projeter un éclairage réaliste sur le filet 3D. Étant donné qu’il s’agit d’un moteur de rendu avancé, il est destiné à la création de jolies images et non à un travail en temps réel. |
| **Variation** | La variation est une propriété du pinceau qui produit un comportement aléatoire lors de la peinture. |
| **Calque** | Un calque est un élément qui contient plusieurs couches avec des propriétés supplémentaires telles qu’un mode de fusion et une opacité. |
| **Pile de calques** | Une pile de calques est un emplacement où les calques peuvent être gérés et organisés. Les calques sont organisés de bas en haut. Le calque inférieur sera dessiné en premier, puis chaque calque supérieur sera ajouté un par un les uns sur les autres. |
| **Souris paresseuse** | La souris relâchée est une fonction de l’outil Pinceau. Cela ralentit le tracé du pinceau pour améliorer la précision lorsque vous peignez, ce qui crée un décalage entre le curseur de la souris et la peinture réelle. |
| **Niveau** | Un niveau est un effet qui permet de contrôler une plage ou des informations de couleur/niveaux de gris via un histogramme. Il peut être utilisé pour inverser la couleur ou obscurcir/éclaircir la couleur, par exemple. |
| **Journal** | Un journal est un fichier texte dans lequel sont écrites des informations provenant du logiciel, généralement liées à l’ordinateur exécutant l’application. |
| **Filet poly faible/élevé** | Un maillage faible et un maillage élevé sont tous deux des maillages 3D, l&#39;un est avec une faible densité de polygones tandis que l&#39;autre est avec une quantité plus élevée de polycount (souvent 100 fois plus grand). Généralement, les informations de maillage élevé sont réduites au maillage faible. |
| **Matière** | Un matériau définit les propriétés pour représenter une matière spécifique. Sur un filet 3D, le matériau est également utilisé pour définir des groupes de faces polygonales. |
| **Maillage** | Un filet est un objet 3D défini par plusieurs informations. Dans Substance 3D Painter, un filet est défini par des polygones (généralement des triangles). Un filet peut être créé dans une application de modélisation 3D telle que **Blender** ou **Autodesk Maya**. |
| **Mappage de maillage** | Une texture de filet est une texture élaborée à partir d’un filet et contenant des informations relatives à ce filet. Il peut s&#39;agir d&#39;une information de position ou d&#39;une information d&#39;occlusion par example. |
| **Mappage Mip** | Une mip-map est une texture précalculée, généralement présente sous la forme d’une séquence d’images, chaque fois à une résolution inférieure à celle de la texture d’origine. |
| **Mode** | Un mode fait référence à la configuration de l’interface qui donne accès à un ensemble spécifique d’outils et de commandes en fonction du mode. |
| **Bruit** | Un bruit est une image procédurale et aléatoire, qui représente généralement des formes organiques et des valeurs de couleur/niveaux de gris. |
| **Normal** | Une normale est une texture spéciale qui déforme le comportement d’une lumière sur la surface d’un filet 3D pour simuler des détails qui n’existent pas dans la géométrie. |
| **OpenGL / DirectX** | OpenGL et DirectX sont deux interfaces de programmation d’application (API) utilisées pour le rendu des informations 2D et 3D. Ils définissent également le format de map normal. |
| **Orthographique** | Une projection orthographique est un moyen de représentation d&#39;objets tridimensionnels en deux dimensions dont toutes les lignes de projection sont orthogonales au plan de projection. |
| **PBR/PBS** | Le rendu basé sur le physique (PBR) ou Ombrage basé sur le physique (PBS) est un modèle d’infographie qui vise à effectuer le rendu des graphiques de manière à modéliser plus précisément le flux de lumière dans le monde réel. |
| **Packing** | L’emballage consiste à conserver plusieurs images dans une même texture. Les textures étant composées de couches séparées Rouge, Vert et Bleu, elles peuvent stocker différentes informations qui peuvent être lues indépendamment dans une autre application. |
| **Particules** | Les particules sont une sorte d’outil qui génère des coups de pinceau en fonction de propriétés physiques ou d’autres comportements complexes. |
| **Perspective** | La perspective est une représentation approximative d’un objet ou d’une scène vu par l’œil humain sur une surface plane (comme un écran). C&#39;est une simulation de profondeur et d&#39;échelle. |
| **Pixel/Texel** | Un pixel est un point dans une image, c&#39;est le plus petit élément possible qui contient des informations de couleur. Plus la résolution est élevée, plus le nombre de pixels disponibles est élevé, ce qui permet une meilleure définition et plus de détails. Les textures sont des pixels à l’intérieur d’une texture. |
| **Plug-in** | Les plug-ins sont des fonctions de programmation (souvent exprimées via des scripts) qui peuvent être ajoutées au logiciel, élargissant ainsi les possibilités de l’application. |
| **Post-traitement** | Un post-traitement est un effet visuel appliqué à l’écran une fois le rendu de l’image 3D effectué, souvent pour simuler un comportement spécial tel que la correction colorimétrique ou l’éclosion. |
| **Procédural** | Le terme procédural est un terme qui décrit les processus générés par un ordinateur à partir d’une série de paramètres. Il peut s’agir simplement de résultats mathématiques tels que des nombres ou des images complexes. |
| **Projection** | Une projection est l’action d’appliquer depuis un point de vue spécifique (comme la caméra) une image/un objet sur la surface du filet 3D. |
| **Résolution (puissance de 2)** | La résolution définit la taille d’une texture sur ses axes X et Y (ou largeur et height). Souvent à une puissance de 2 échelles (2, 4, 8, 16... 512, 1024, 2048...) car il est optimisé pour les calculs sur un GPU. |
| **Scripts** | La création de scripts consiste à exécuter des comportements spécifiques à l’aide d’une commande spécifique via un format de fichier texte. |
| **Nuanceur** | Un shader définit le comportement d&#39;un matériau lorsqu&#39;il reçoit des informations d&#39;éclairage. Certains ombrages peuvent être simples (comme l’ombrage de ton) ou plus avancés (comme l’ombrage de peau qui simule l’absorption de la lumière dans une surface). |
| **Étagère** | Une étagère est l’emplacement dans l’application où les ressources de plusieurs types sont organisées. Il peut aller d&#39;images simples à des outils plus complexes. |
| **Masque dynamique** | Les masques intelligents se comportent comme des matériaux intelligents, mais au lieu d’être des calques, il s’agit d’effets définis pour générer un masque uniquement sur la base du maillage 3D actuel. |
| **Matière intelligente** | Groupe de calques enregistrés dans un fichier. Les matériaux intelligents peuvent s’adapter à chaque projet dans Substance 3D Painter, ce qui permet de créer des matériaux qui changeront en fonction du maillage 3D actuel. |
| **Doigt** | L’outil Doigt permet de déborder, d’étaler ou de mélanger des couleurs. Cet outil est souvent utilisé pour adoucir les pixels. |
| **Pochoir** | Un pochoir est une image alignée sur l’écran et utilisée avec une projection de caméra pour peindre sur le filet 3D. |
| **Substance** | Une Substance est un format de fichier qui permet de générer une texture à partir d’un ensemble de paramètres (qui impliquent des calculs procéduraux). Ces paramètres peuvent être modifiés pour créer des variations. |
| **Symétrie** | La symétrie est une option d’un outil qui permet de peindre en miroir à deux endroits en même temps. |
| **Modèle** | Un modèle est un ensemble d’options prédéfinies utilisées lors de la création d’un projet. Il peut définir la résolution par défaut ou le paramètre de cuisson par défaut, par exemple. |
| **Rapport Texel** | Le rapport des texels est la règle qui compare la taille d’un Îlot UV (2D) et la géométrie du maillage 3D qui lui est associé. Un bon rapport texel signifie un dépliement régulier de la géométrie en 2D. Il est important de conserver l’aspect et la qualité de la peinture/texture de manière cohérente sur le filet 3D. |
| **Texture** | Une texture est un fichier contenant des pixels en 2 dimensions, définis par une résolution. Les pixels peuvent être en niveaux de gris ou colorés. Lorsqu’ils sont colorés, les pixels peuvent avoir des informations de transparence (si le format de fichier le prend en charge). |
| **Ensemble de textures** | Dans Substance 3D Painter, un ensemble de textures représente une partie d’un filet sur lequel des UV spécifiques sont à peindre. Le jeu de textures est créé par matière unique détectée lors de l’importation d’un filet 3D. |
| **Facturation** | Le labourage est la répétition d’une texture où les coutures ne sont pas visibles aux bords. Il est destiné à simuler un plan infini. Exemple : gazon ou trottoirs. |
| **Outil** | Un outil fait référence à une action qui permet d’interagir avec le filet 3D, souvent pour peindre ou appliquer des effets. |
| **Barre d&#39;outils** | La barre d’outils est l’emplacement où tous les raccourcis d’icônes vers les outils sont disponibles. |
| **UDIM** | L’UDIM permet de fractionner les UV d’un filet 3D sur plusieurs plages afin d’augmenter la résolution générale de la texture. |
| **UV** | Les UV sont des informations définies sur un filet 3D qui indiquent comment le déplier pour obtenir une forme plate. Ces informations sont utilisées pour projeter une texture sur un filet 3D. Substance 3D Painter permet uniquement de peindre dans la plage 0-1 qui représente la taille d’une texture. Les autres plages ne sont prises en charge que par le système UDIM. |
| **VRam** | Le VRam est la mémoire du GPU (carte graphique), utilisée pour stocker les informations et la texture lors des calculs. Plus la quantité de RVam est importante, mieux c’est pour travailler avec Substance 3D Painter. |
| **Fenêtre d&#39;affichage** | Endroit où la scène 3D ou 2D s’affiche à l’écran. C’est également là qu’il est possible d’interagir avec les outils et le maillage 3D en contrôlant la caméra. |

# Ajout de ressources via la fenêtre d’importation

## Ouverture de la fenêtre d’importation

Il existe trois manières différentes d’ouvrir la fenêtre d’importation dans Substance 3D Painter :

* Via l’entrée de menu **Fichier > Importer des ressources...**

![](../../assets/05-01-importfilemenu.jpg)

* Via le **bouton dédié** dans la fenêtre Actifs

![](../../assets/05-03-importbutton.jpg)

* Via **glisser-déposer** d’un ou plusieurs fichiers/dossiers dans la fenêtre Actifs

![](../../assets/05-02-importdnd.gif){width="700px"}

## Configuration de la fenêtre d’importation

![](../../assets/05-04-importwindow.jpg)

* **1 - Ajouter des ressources** : permet de sélectionner des fichiers supplémentaires à importer, qui les ajouteront à la liste affichée dans la fenêtre d&#39;importation.
* **2 - Supprimer les ressources sélectionnées :** supprime les fichiers sélectionnés dans la liste.
* **3 - Filtre déroulant** : permet de filtrer la liste des fichiers par utilisation. Ceci est utile pour isoler les ressources dont le type est « non défini ».
* **4 - Utilisation** : plusieurs types d&#39;utilisation différents sont disponibles. La liste des utilisations proposées peut changer en fonction du format de fichier que vous importez. L’utilisation peut être présélectionnée pour votre fichier si votre format de fichier n’a qu’un seul type d’utilisation (par exemple, les paramètres prédéfinis Painter .sppr seront automatiquement définis comme tels) OU s’ils ont été prédéfinis dans le graphique Designer d’origine par son créateur.
* **5 - Préfixe** : le préfixe peut être un chemin de dossier pour définir où stocker une ressource.
* **6 - Nom de fichier** : nom de la ressource actuelle. Parfois, le dossier où la ressource a été stockée peut être indiqué, ces informations ne seront pas utilisées pendant le processus d&#39;importation.
* **7 - Emplacement d&#39;importation** : peut être -
  * **Session actuelle** : dans une session temporaire, les ressources seront perdues après un redémarrage de l&#39;application.
  * **Project « project name »** : dans le fichier de projet actuellement ouvert. Les ressources sont incorporées dans le fichier **spp**.
  * **Conserver le « nom de l&#39;étagère »** : dans la bibliothèque actuelle définie comme accessible en écriture. Consultez cette page pour plus d&#39;informations : [Configuration des bibliothèques](../../interface/settings/libraries-configuration.md).

Vous pouvez sélectionner plusieurs ressources dans la fenêtre d’importation (à l’aide des raccourcis système habituels) pour modifier rapidement leur utilisation.

# Réception de ressources d’autres applications Substance 3D

À partir de la version 7.2.0, vous pouvez également recevoir et mettre à jour des ressources envoyées à partir de Designer et Sampler via la fonction Envoyer à. Comme vous devez pouvoir accéder à Sampler et Designer pour cela, cette fonctionnalité n’est disponible que si vous utilisez Painter via le module Texturation de Substance 3D ou la collection Substance 3D.

Une fois la ressource envoyée, elle apparaîtra dans le panneau Ressources Painter, importée dans l’emplacement de bibliothèque par défaut sur le disque. Vous pouvez également **mettre à jour** les ressources envoyées si vous avez apporté des modifications dans Designer ou Sampler **au cours de la même session** (à condition qu’aucune des applications n’ait été fermée).

## Envoi d’une ressource de Designer vers Painter

1. Dans le panneau Explorateur, sélectionnez votre pack principal.
1. Cliquez sur le menu déroulant Publish (vous pouvez également cliquer avec le bouton droit de la souris sur le package principal).
1. Sélectionnez l&#39;option **Envoyer vers Substance 3D Painter** (cela lancera automatiquement Painter s&#39;il n&#39;est pas déjà ouvert).
1. La ressource envoyée apparaît dans la fenêtre Ressources.

![](../../assets/05-06-fromdesigner.jpg)

## Envoi d’une ressource de Sampler vers Painter

1. Dans la barre d’outils de droite, ouvrez le panneau Partager.
1. Cliquez sur **Envoyer vers Substance 3D Painter** (cela lancera automatiquement Painter s’il n’est pas déjà ouvert).
1. La ressource envoyée apparaît dans la fenêtre Ressource.

# Configuration du pare-feu

Substance 3D Painter a parfois besoin de communiquer à l’extérieur certaines informations qui peuvent nécessiter une liste blanche dans le logiciel de pare-feu.

| Description | Port | URL |
| --- | --- | --- |
| Rapport de crash | 80 | <https://bugs.allegorithmic.com/api/crash> |
| Rapport de bogue | 80 | <https://bugs.allegorithmic.com/api/bug> |

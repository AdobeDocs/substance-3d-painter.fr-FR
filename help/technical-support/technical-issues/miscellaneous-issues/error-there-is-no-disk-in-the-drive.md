# Erreur : le lecteur ne contient aucun disque

Sous Windows, vous pouvez parfois rencontrer cette erreur :

« Il n&#39;y a pas de disque dans le lecteur. Insérez un disque dans le lecteur X. »

![](../../../assets/disk-drive-error.png)

Il y a quelques éléments à vérifier pour se débarrasser de cette erreur :

* Vérifiez que la configuration de vos lettres de lecteur est correcte (voir <https://support.microsoft.com/en-us/kb/330137> )
* Vérifiez que tout emplacement précédent utilisé dans Substance 3D Painter est valide (comme la liste « Fichiers récents »).

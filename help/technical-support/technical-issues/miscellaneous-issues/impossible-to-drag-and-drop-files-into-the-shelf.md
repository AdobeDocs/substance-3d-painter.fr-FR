# Impossible de glisser-déposer des fichiers dans l’étagère

Sur **Windows 8 et Windows 10**, si vous exécutez Substance 3D Painter en mode administrateur, le niveau de sécurité du logiciel sera probablement supérieur au niveau de sécurité de l&#39;Explorateur Windows. Par conséquent, Windows n’autorisera pas le glisser-déposer de fichiers entre ces applications.

Pour résoudre ce problème, vous pouvez :

* Exécutez Substance 3D Painter normalement (sans droits d’administrateur).
* Désactivez l&#39;UAC (ceci n&#39;est **pas recommandé** ).

>[!NOTE]
>
> Il est également possible d’importer des ressources en ouvrant simplement la fenêtre d’importation :
> 
> 1. Cliquez sur le menu « Fichier »
> 1. Sélectionnez « Importer des ressources... ».
> 1. Dans la fenêtre d&#39;importation, cliquez sur « Ajouter des ressources » pour sélectionner vos fichiers

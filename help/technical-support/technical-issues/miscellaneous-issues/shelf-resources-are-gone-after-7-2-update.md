# Les ressources d’Étagère ont disparu après la mise à jour 7.2

Cette page explique pourquoi les ressources ont pu disparaître et comment les restaurer.

Après la mise à jour vers la version 7.2 (ou plus récente), les ressources personnalisées de l’Étagère telles que les caractères alphanumériques, les filtres, les matériaux, les matériaux adaptables ou même les masques adaptables peuvent avoir disparu. Cela est dû au fait que cette nouvelle version a réinitialisé les préférences et que les fichiers se trouvent désormais dans un autre dossier. Les anciennes ressources sont uniquement ignorées et peuvent être restaurées en copiant les fichiers manuellement. Pour ce faire, consultez le [guide de migration](../../../pipeline-and-integration/resource-management/preferences-and-content-migration.md).

# Les ressources de stockage ont disparu après la mise à jour 7.2

Cette page explique pourquoi les ressources ont pu disparaître et comment les restaurer.

Après la mise à jour vers la version 7.2 (ou plus récente), les ressources personnalisées du tiroir telles que les alpha, les filtres, les matériaux, les matériaux intelligents ou même les masques intelligents peuvent avoir disparu. Cela est dû au fait que cette nouvelle version a réinitialisé les préférences et que les fichiers se trouvent désormais dans un autre dossier. Les anciennes ressources sont uniquement ignorées et peuvent être restaurées en copiant les fichiers manuellement. Pour ce faire, consultez le [guide de migration](../../../pipeline-and-integration/resource-management/preferences-and-content-migration.md).

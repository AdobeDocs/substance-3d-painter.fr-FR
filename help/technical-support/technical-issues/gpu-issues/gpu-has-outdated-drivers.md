# Le GPU a des pilotes obsolètes

![](../../../assets/driver-outdated.png){width="500px"}

Lors du lancement de Substance 3D Painter, une fenêtre contextuelle peut s’afficher, indiquant que les pilotes GPU sont obsolètes. Ce message signifie simplement que le logiciel nécessite une version minimale des pilotes GPU pour être installé. Nous vous recommandons de mettre à jour les pilotes GPU vers la dernière version disponible lorsque cela est possible pour obtenir la meilleure expérience de travail.

| *Fournisseur* | *Lien* |
| --- | --- |
| **NVIDIA** | [http://www.nvidia.com/Download/index.aspx](http://www.nvidia.com/Download/index.aspx?lang=en-us) <ul data-preserve-html="true"><li data-preserve-html="true"><strong> GeForce </strong> : version « Studio Drivers » (SD) recommandée.</li><li data-preserve-html="true"><strong> Quadro </strong> : version « Optimal Driver for Enterprise » (ODE) recommandée.</li></ul> |
| **AMD** | <http://support.amd.com/en-us/download> |
| **Intel** | <https://downloadcenter.intel.com/> |

>[!NOTE]
>
> Certains ordinateurs <b>peuvent avoir deux GPU</b> : un intégré (comme un chipset Intel) et un dédié (comme une carte graphique Nvidia). <b>Les deux</b> doivent être <b>à jour</b> pour réduire le risque de bogues dans Painter.

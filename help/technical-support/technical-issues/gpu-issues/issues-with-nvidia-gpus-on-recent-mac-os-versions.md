# Problèmes avec les GPU Nvidia sur les versions récentes du système d’exploitation Mac

Sous Mac OS, Apple fournit les pilotes GPU en les validant après qu’ils ont été fournis par le constructeur GPU. Depuis Mac OS Mojave, Apple n’a pas encore validé de nouveaux pilotes pour les GPU Nvidia récents. Malheureusement, Substance 3D Painter a besoin de pilotes GPU à jour pour fonctionner correctement.

Pour plus d’informations, reportez-vous à la page suivante :

* [Liste des GPU pris en charge sur le système d’exploitation Mac](https://support.apple.com/en-us/HT208898) .
* [Utilisation d’un GPU externe sur le système d’exploitation Mac](https://support.apple.com/en-us/HT208544) .

# Exportation du fichier journal

Cette page explique comment trouver le fichier journal de l’application et comment le partager pour demander de l’aide.

## Récupération du fichier journal

Il existe deux façons d’obtenir le fichier journal :

### Exportation du fichier journal à partir de l’application

Le fichier journal peut être exporté directement à partir de l&#39;application en accédant au menu **Aide** et en sélectionnant l&#39;action **Exporter le journal**.

![](../assets/screenshot-20210622-195334.png)

### Récupération manuelle du fichier journal sur le disque

Si l’application ne se lance pas, il ne sera pas possible d’exporter le fichier journal. Heureusement, le fichier journal peut être localisé manuellement sur le disque. Accédez au dossier correspondant à votre système d&#39;exploitation ci-dessous et récupérez le fichier **log.txt** manuellement.

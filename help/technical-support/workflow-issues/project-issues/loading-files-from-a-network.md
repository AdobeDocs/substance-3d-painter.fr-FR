# Chargement de fichiers à partir d’un réseau

Substance 3D Painter ne prend pas en charge les chemins d&#39;accès réseau, car cela nécessite une **authentification de compte**, ce que le logiciel ne peut pas faire.\
Par conséquent, les chemins doivent être **mappés** / **montés** par le système d&#39;exploitation.

* **Windows** : <http://www.laptopmag.com/articles/map-network-drive-windows-10>
* **MacOS** : <http://osxdaily.com/2010/09/20/map-a-network-drive-on-a-mac/>
* **Linux** : <http://superuser.com/questions/145191/how-do-i-map-a-drive-network-share-using-the-linux-terminal>

# Curseurs

Cette page explique comment utiliser les curseurs dans l’interface de l’application.

| Action | Exemple | Description |
| --- | --- | --- |
| **Faire Glisser** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/drag-slider.gif"/></div> | Cliquez et faites glisser lorsque vous survolez un curseur pour modifier sa valeur. |
| **Glissement de précision** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/precision-slider.gif"/></div> | Maintenez la touche Maj enfoncée tout en cliquant pour augmenter la distance de glissement du curseur. Ce raccourci permet de régler avec plus de précision le curseur tout en le faisant glisser. |
| **Aller** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/jump-slider.gif"/></div> | Cliquez n’importe où sur un curseur pour passer à la valeur située sous la position de la souris. |
| **Haut/Bas** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/up-down-sliders.gif"/></div> | Après avoir obtenu la mise au point d’un curseur en cliquant dessus, utilisez les touches fléchées Haut et Bas du clavier pour augmenter ou diminuer la valeur étape par étape. |
| **Édition Value** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r5-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/value-edit-slider.gif"/></div> | Cliquez dans le champ de texte juste au-dessus d’un curseur pour modifier manuellement sa valeur via le clavier. |

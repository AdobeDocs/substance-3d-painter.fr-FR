# Ensemble de textures

![](../../assets/texture-set.png)

Substance 3D Painter crée automatiquement un nouvel ensemble de textures chaque fois qu&#39;il trouve un ID de matière sur un maillage importé ([sauf si un projet utilise le workflow de mosaïque UV](../../features/uv-tiles/uv-tiles.md)).

Chaque ID de matériau doit avoir des UV uniques (ou des chevauchements logiques pour la géométrie mise en miroir).

Pour plus de détails sur les propriétés et les manipulations du **ensemble de textures**, voir :

* [Liste des ensembles de textures](texture-set-list.md)
* [Paramètres du jeu de textures](texture-set-settings.md)
* [Réaffectation du jeu de textures](texture-set-reassignment.md)

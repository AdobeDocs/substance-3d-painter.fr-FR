# Recherches enregistrées

Les recherches enregistrées, à côté de Filtrer par chemin, constituent une autre nouvelle section qui peut être ouverte dans la fenêtre Ressource. Il vous permet d&#39;enregistrer vos recherches et requêtes les plus fréquentes, d&#39;y accéder facilement à tout moment et même de les ouvrir en tant que nouvel onglet de sous-bibliothèque pouvant être ancré séparément.

![](../../assets/02-01-savedsearches.jpg)

Pour créer une recherche enregistrée, il est possible de combiner différents types de navigation : vous pouvez saisir une requête écrite dans le champ de recherche, sélectionner le type de ressource souhaité (ou plusieurs types de ressources) et un emplacement via Filtrer par chemin ou Chemins de navigation. Tous ces éléments peuvent être enregistrés sous la forme d’une seule recherche enregistrée ou être divisés en recherches enregistrées distinctes. Par exemple, vous pouvez créer une recherche enregistrée pour les pinceaux qui utilisent des contours dynamiques, car c’est un outil que vous utilisez assez souvent.

>[!NOTE]
>
> Les recherches enregistrées sont enregistrées dans un fichier de configuration qui peut être modifié manuellement. Pour en savoir plus, consultez la section [Ajout manuel de recherches enregistrées](../../pipeline-and-integration/resource-management/adding-saved-searches-manually.md).

Une fois que vous avez créé votre recherche enregistrée, elle apparaîtra dans votre liste de recherches. Vous pouvez cliquer dessus avec le bouton droit pour créer un nouvel onglet de sous-bibliothèque, le renommer ou le supprimer.

![](../../assets/02-02-savesearch.gif)

Vous pouvez également afficher des informations sur le contenu de votre recherche en survolant la balise de recherche dans le champ de recherche.

![](../../assets/02-03-searchinfo.jpg)

# Gestion des calques

Voici les manipulations possibles dans la pile de calques :

| *Action* | *Démonstration* |
| --- | --- |
| Cliquez et faites glisser pour déplacer un calque. Lors du déplacement d’un calque, une barre peut être visible indiquant où le calque sera placé :<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Barre au-dessus d&#39;un calque</strong> : le calque sera placé au-dessus du calque</li><li data-preserve-html="true"><strong>Barre entre deux calques</strong> : le calque sera placé entre les deux calques</li><li data-preserve-html="true"><strong>Barre sous un calque</strong> : le calque sera placé sous le calque</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-above.gif"/></div> |
| **Placer dans un dossier** : cliquez et déposez un calque au-dessus d&#39;un dossier pour le placer à l&#39;intérieur | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-folder.gif"/></div> |
| **Sélection multiple** : deux méthodes différentes permettent d&#39;effectuer cette sélection :<ul data-preserve-html="true"><li data-preserve-html="true">Maintenez la touche Ctrl ou Commande enfoncée</li><li data-preserve-html="true">Appuyez sur la touche Maj tout en cliquant sur le premier et le dernier calque</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-ctrlselect.gif"/></div><div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid1_items_grid-cell_position-par_image" src="../../assets/dragdrop-shiftselect.gif"/></div> |
| **Regroupement des calques** : un dossier peut être créé avec le calque actuellement sélectionné en procédant de l’une des façons suivantes :<ul data-preserve-html="true"><li data-preserve-html="true">Cliquez avec le bouton droit > Associer les calques</li><li data-preserve-html="true">Appui sur les touches Ctrl + G ou Commande + G</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/group-layer.gif"/></div> |

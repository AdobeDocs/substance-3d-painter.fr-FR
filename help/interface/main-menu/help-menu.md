# Menu Aide

<table style="table-layout:auto">
  <tr style="border: 0;">
    <td style="border: 0;" valign="top">Le menu Aide contient des liens et des options qui vous permettent d’en savoir plus sur Substance 3D Painter. Cela inclut du contenu utile, tel que des tutoriels, des notes de mise à jour et de la documentation, ou des emplacements où vous pouvez résoudre les problèmes liés à votre installation locale de Painter, y compris l’accès aux journaux ou un moyen de signaler les bogues.</td>

  </tr>
</table>

| --- | --- |
| Tutoriels | Lien vers les [tutoriels](https://helpx.adobe.com/fr/substance-3d/unlisted/tutorials.html) officiels liés à l&#39;application. |
| Notes de mise à jour | Lien vers les [notes de mise à jour](../../release-notes/all-changes.md) |
| Documentation | Lien vers cette documentation. |
| Liste des raccourcis | Lien vers la documentation sur les [raccourcis](../settings/shortcuts.md). |
| Documentation sur l&#39;API de scripting | Lien vers la documentation locale des différentes API de script. |
| Forums | Lien vers les [forums d&#39;applications](https://community.adobe.com/t5/substance-3d-painter/bd-p/substance-3d-painter). |
| Signaler un bogue | Ouvrez la fenêtre de rapport de bogue pour envoyer des informations. |
| Afficher le journal | Ouvrez le fichier journal de votre session Painter actuelle dans votre éditeur de fichiers TXT par défaut. |
| Exporter le journal | Exportez le fichier journal pour demander de l’aide auprès de notre assistance. |

| Écran de bienvenue | Ouvrez la fenêtre de l&#39;[écran d&#39;accueil](../../getting-started/getting-started.md). |

| Écran d’accueil | Ouvrez l’écran Accueil. |
| Rechercher des mises à jour | Ouvrez la fenêtre [vérificateur de mise à jour](../miscellaneous/update-checker.md). |
| À propos de Substance 3D Painter | Ouvrez la fenêtre À propos qui affiche la version de l’application, les mentions légales et d’autres détails. |
| Partenaires | Accédez aux informations sur les logiciels partenaires intégrés dans Painter. |

# Menus de plug-ins JavaScript et Python

![](../../assets/plugins-javascript.png)

Les menus JavaScript et Python répertorient tous les plug-ins chargés par Painter au démarrage. Les plug-ins sont séparés en deux menus en fonction de l’API de script qu’ils utilisent (JavaScript ou Python).

Chaque plug-in découvert par l’application ajoutera une entrée dans le menu correspondant pour accéder à des fonctions supplémentaires. Dans les menus, chaque plug-in dispose des options suivantes :

* **désactiver/activer** : activez ou désactivez le plug-in.
* **recharger** : rechargez le plug-in au cas où le script aurait été mis à jour pendant l&#39;exécution de l&#39;application.
* **configurer** : si le plug-in est pris en charge, affiche la fonction/fenêtre pour configurer le plug-in.
* **à propos** : si le module externe est pris en charge, affiche des informations sur le module externe.

Pour en savoir plus sur les plug-ins par défaut fournis avec Painter ou comment en créer vous-même, consultez la page [Plug-ins](../../features/plugins/plugins.md) dédiée.

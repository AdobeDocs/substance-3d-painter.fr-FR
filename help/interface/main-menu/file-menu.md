# Menu Fichier

![](../../assets/file-menu.png){width="150px"}

Le menu Fichier contient les actions permettant de créer et d’enregistrer les projets, ainsi que les actions permettant d’exporter et d’importer des ressources dans un projet.

| Action | Description |
| --- | --- |
| **Nouveau** | Ouvrez la fenêtre de création du nouveau projet. Voir : [Création de projet](../../getting-started/project-creation.md)pour plus d&#39;informations. |
| **Ouvrir** | Ouvrez un fichier de projet existant sur le disque. |
| **Fichiers récents** | Répertoriez tous les projets récemment ouverts. |
| **Ouvrir l&#39;exemple** | Ouvrez l’un des projets d’exemple fournis avec l’application. |
| **Fermer** | Fermez le projet actuellement ouvert. |
| **Enregistrer** | Enregistrez le projet en cours sur place. |
| **Enregistrer et compresser** | Enregistrez le projet en cours et compressez-le (réduisez l’encombrement sur le disque). |
| **Enregistrer sous** | Enregistrez le projet actuel sous un nouveau nom et à un nouvel emplacement. |
| **Enregistrer en tant que copie** | Enregistrez le projet actuel sous un nouveau nom et à un nouvel emplacement en tant que copie et gardez le projet actuel ouvert. |
| **Enregistrer comme modèle** | Enregistrez les paramètres du projet en cours dans un fichier modèle pouvant être utilisé pour un nouveau projet. |
| **Nettoyer** | Supprimez toutes les ressources inutilisées du projet actuel (cette action prendra effet après le **enregistrement** suivant). |
| **Importer des ressources** | Ouvrez la fenêtre Importer des ressources. |
| **Exporter le maillage** | Ouvrez la fenêtre d’exportation de filet qui permet d’exporter le projet actuel en tant que fichier de modèle 3D. |
| **Exporter des textures** | Ouvrez la fenêtre d’exportation de texture qui permet d’exporter le projet actuel en tant que textures bitmap. |
| **Envoyer à** | Répertoriez toutes les actions **Envoyer à** pour envoyer un projet à une autre application. |
| **Quitter** | Fermez l’application. Si le projet actuel contient des modifications non enregistrées, un message s’affiche. |

>[!NOTE]
>
> L’enregistrement d’un projet peut être effectué de deux manières :
> 
> * **Incrémentiel** : méthode par défaut, utilisée lors d’un enregistrement normal. Seules les informations modifiées seront mises à jour dans le fichier de projet sur le disque. Cette méthode permet d’enregistrer très rapidement le projet sans avoir à réécrire entièrement le fichier du projet.
> * **Complet/Compact** : si une opération Clean est effectuée ou si le projet est enregistré avec l’action « Enregistrer et compacter », la méthode réécrit entièrement le projet sur le disque. Cette méthode permet de se débarrasser de la fragmentation du projet et de réduire l’empreinte. Voir : [Les projets sont très volumineux](../../technical-support/workflow-issues/project-issues/projects-are-really-big.md).

# menu viewport

![](../../assets/viewport-menu.png)

Le menu viewport peut être utilisé pour modifier le mode d&#39;affichage des [Viewports](https://substance3d.adobe.com/).

| Action | Description |
| --- | --- |
| **Afficher le matériau** | Basculez les viewports en mode **Matériau** qui affiche le modèle 3D avec éclairage et ombrage. |
| **Afficher le canal suivant** | Basculez les viewports en mode Solo pour afficher la couche de Jeu de textures suivante. |
| **Afficher le canal précédent** | Basculez les viewports en mode Solo pour afficher la couche de Jeu de textures précédente. |
| **Afficher la map de maillage suivante** | Basculez les viewports en mode Solo pour afficher le type de Map de maillage baké suivant. |
| **Afficher la map de maillage précédente** | Basculez les viewports en mode Solo pour afficher le type de Map de maillage baké précédent. |
| **Afficher le maillage entier** | Ajustez la caméra du viewport pour la centrer sur le modèle 3D. |
| **masque rapide activé** | Consultez la page [Masque rapide](../../painting/tool-list/quick-mask.md) pour plus d&#39;informations. |
| **Modifier le masque rapide** | Consultez la page [Masque rapide](../../painting/tool-list/quick-mask.md) pour plus d&#39;informations. |
| **Inverser le masque rapide** | Consultez la page [Masque rapide](../../painting/tool-list/quick-mask.md) pour plus d&#39;informations. |

Pour plus d&#39;informations sur les modes d&#39;affichage, consultez les [paramètres d&#39;affichage](../display-settings/display-settings.md).

Pour plus d&#39;informations sur le Masque rapide, consultez la [page dédiée](../../painting/tool-list/quick-mask.md).

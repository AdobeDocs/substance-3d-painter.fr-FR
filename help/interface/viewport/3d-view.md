# Vue 3D

![](../../assets/3d-view.jpg){width="370px"}

La vue 3D montre le modèle 3D dans des conditions d’éclairage qui permettent d’examiner la définition du matériau de surface. C’est également là qu’il est possible de peindre directement sur le modèle 3D.

## Profil

Un texte indiquant le profil chargé peut apparaître dans la partie supérieure gauche de la clôture. Pour plus d&#39;informations, consultez la page [Profil colorimétrique](../../features/post-processing/color-profile.md).

## Sélection de la caméra

![](../../assets/display-mode.png)

Si des caméras sont définies dans le fichier de modèle 3D utilisé pour créer le projet ou importer le filet, elles peuvent être importées dans le projet et utilisées pour modifier l’emplacement et l’orientation de la caméra. Cette liste déroulante permet de basculer entre les caméras disponibles dans le projet. S’il n’y a pas d’autre appareil photo que celui par défaut, la liste déroulante ne s’affiche pas.

Le basculement entre les appareils photo peut être effectué rapidement à l&#39;aide du [raccourci clavier](../settings/shortcuts.md) dédié. Pour plus d&#39;informations, consultez la page [Gestion des appareils photo](camera-management.md).

## Mode d’affichage

![](../../assets/display-mode.png)

Par défaut, le mode d&#39;affichage de la fenêtre d&#39;affichage est défini sur matériau pour afficher l&#39;éclairage de l&#39;environnement. La liste déroulante permet de passer du mode d’affichage au mode solo qui isole individuellement les canaux et les maillages.

Cet éclairage peut être contrôlé via les [paramètres d&#39;affichage](../display-settings/display-settings.md) ainsi que d&#39;autres paramètres de rendu. L&#39;orientation de l&#39;éclairage peut également être modifiée à l&#39;aide du [raccourci clavier](../settings/shortcuts.md).

## Axe

![](../../assets/3d-axis.png)

En bas à droite de la fenêtre d’affichage se trouve l’axe de vue 3D qui indique l’orientation de la scène par rapport à la caméra.

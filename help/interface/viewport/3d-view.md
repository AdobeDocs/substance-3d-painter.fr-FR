# Vue 3D

![](../../assets/3d-view.jpg){width="370px"}

La vue 3D montre le modèle 3D dans des conditions d’éclairage qui permettent de voir comment le matériau de surface est défini. C’est également là qu’il est possible d’effectuer une peinture directe sur le modèle 3D.

## Profil

En haut à gauche du viewport, un texte peut apparaître indiquant le profil actuellement chargé. Pour plus d&#39;informations, consultez la page [Profil colorimétrique](../../features/post-processing/color-profile.md).

## sélection de caméra

![](../../assets/display-mode.png)

Si des caméras sont définies dans le fichier de maillage 3D utilisé pour créer le projet ou importer le projet, elles peuvent être importées dans le projet et utilisées pour modifier l’emplacement et l’orientation de la Caméra. Cette liste déroulante permet de basculer entre les caméras disponibles dans le projet. S’il n’existe aucune autre caméra que la valeur par défaut, la liste déroulante ne s’affiche pas.

Le basculement entre les caméras peut être effectué rapidement à l&#39;aide du [raccourci clavier](../settings/shortcuts.md) dédié. Pour plus d&#39;informations, consultez la page [Gestion des Caméras](camera-management.md).

## Mode d’affichage

![](../../assets/display-mode.png)

Par défaut, le mode d’affichage viewport est défini sur matériau pour afficher l’éclairage de l’environnement. La liste déroulante permet de passer du mode d’affichage au mode solo qui isole les canaux et les maps de maillage individuellement.

Cet éclairage peut être contrôlé via les [paramètres d&#39;affichage](../display-settings/display-settings.md) ainsi que d&#39;autres paramètres de rendu. L&#39;orientation de l&#39;éclairage peut également être modifiée à l&#39;aide du [raccourci du clavier](../settings/shortcuts.md).

## Axe

![](../../assets/3d-axis.png)

En bas à droite du viewport se trouve l’axe de la vue 3D qui indique l’orientation de la scène par rapport à la caméra.

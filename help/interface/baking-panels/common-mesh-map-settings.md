# Panneau Paramètres communs

En [**mode Baking**](../../baking/baking.md), le **panneau des paramètres communs** affiche les paramètres pertinents pour toutes les maps de maillage.

>[!NOTE]
>
> Les paramètres du panneau Paramètres communs s’appliquent à toutes les maps de maillage lors du baking. Il n’existe aucun moyen de remplacer les paramètres courants d’une map de maillage spécifique.
>
> Si, par exemple, vous souhaitez baker des Maps normal à une résolution plus élevée, vous devez :
>
> 1. **Bakez** vos mappages à la résolution inférieure.
> 1. **Décochez** les autres maps de maillage afin que seule l&#39;option Normal soit **cochée**.
> 1. Modifiez les paramètres communs **Taille de sortie**.
> 1. **Baker** la Map normal.

Une liste complète des paramètres de map de maillage disponibles dans les **paramètres communs** et les [**panneaux des paramètres de Map de maillage**](mesh-map-settings.md) est disponible [dans la section baking de la documentation](../../baking/mesh-map-settings.md).

# Panneau Paramètres de maillage

En [**mode d&#39;ancrage**](../../baking/baking.md), le panneau **Paramètres de mappage de maillage** affiche les paramètres pour le type de mappage de maillage actuellement sélectionné dans le panneau **Mappage de maillage**.

Une liste complète des paramètres de mappage de maillage disponibles dans les [**paramètres communs**](common-mesh-map-settings.md) et les **panneaux Paramètres de mappage de maillage** est disponible [dans la section boulangerie de la documentation](../../baking/mesh-map-settings.md).

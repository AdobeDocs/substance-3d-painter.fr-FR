# Panneau Paramètres de map de maillage

En [**mode Baking**](../../baking/baking.md), le **panneau des paramètres de Map de maillage** affiche les paramètres du type de map de maillage actuellement sélectionné dans le **panneau des bakers de Map de maillage**.

Une liste complète des paramètres de map de maillage disponibles dans les [**paramètres communs**](common-mesh-map-settings.md) et les **panneaux des paramètres de Map de maillage** est disponible [dans la section baking de la documentation](../../baking/mesh-map-settings.md).

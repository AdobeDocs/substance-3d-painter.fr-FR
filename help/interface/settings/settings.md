# Paramètres

![](../../assets/settings-general.png){width="400px"}

Ouvrez les <b>Paramètres </b> dans le <b>menu Modifier </b> pour ajuster vos préférences concernant votre façon de travailler avec Painter.

Les <b>paramètres </b> sont divisés en trois sections :

* [Préférences générales](general-preferences.md)
* [Raccourcis](shortcuts.md)
* [Configuration des bibliothèques](libraries-configuration.md)

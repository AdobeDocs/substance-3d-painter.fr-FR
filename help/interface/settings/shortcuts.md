# Raccourcis

![](../../assets/settings-shortcuts.png){width="400px"}

Cette page répertorie tous les raccourcis clavier et souris disponibles.

## Présentation des raccourcis

Pour un aperçu rapide de tous les raccourcis disponibles, consultez notre graphique [disponible dans nos tutoriels](https://helpx.adobe.com/substance-3d/unlisted/tutorials/courses/substance-3d-painter-keyboard-shortcuts.html) .

## Comment modifier un raccourci

![](../../assets/shortcut-edit.gif)Cliquez sur l’icône « stylet » à côté d’un raccourci pour le modifier et entrer la nouvelle combinaison.Appuyez sur la dernière touche pour quitter automatiquement le mode d’édition et modifier le raccourci.

## Liste des raccourcis non modifiables

Certains raccourcis peuvent **ne fonctionner** que si la **souris se trouve** au-dessus de la fenêtre spécifique.

Exemple : **copier** et **coller** nécessite que la souris se trouve **sur la pile de calques**.

| *Action* | *Raccourci (Windows)* | *Raccourci (MacOS)* | Description |
| --- | --- | --- | --- |
| **Copier le calque** | Ctrl + C | ⌘+C | Copiez le ou les calques actuellement sélectionnés. |
| **Couper le calque** | Ctrl + X | ⌘+X | Coupez le(s) calque(s) sélectionné(s). |
| **Coller le calque** | Ctrl + V | ⌘+V | Collez le calque en mémoire. |
| **Supprimer le calque** | Supprimer | Supprimer | Supprimez le ou les calques actuellement sélectionnés. |
| **Dupliquer le calque** | Ctrl + D | ⌘+D | Dupliquez le ou les calques actuellement sélectionnés. |
| **Calque de groupe** | Ctrl + G | ⌘+G | Placez le ou les calques actuellement sélectionnés dans un dossier. |
| **Copier le contenu du calque** | Ctrl + Maj + C | Option + ⌘ + C | Copiez le contenu du calque (peinture) et ses effets. |
| **Coller le contenu du calque** | Ctrl + Maj + V | Option + ⌘ + V | Collez le contenu (peinture) et les effets actuellement en mémoire. |
| **Afficher le masque dans viewport** | Alt + Souris à gauche | Option+Souris à gauche | Bascule le mode d’affichage du viewport sur celui du calque spécifié. |
| **Désactiver/Activer le masque** | Maj + Souris + Touche gauche | Maj + Souris + Touche gauche | Activer/désactiver l’état du masque sur un calque. |
|  |  |  |  |
| **Glisser-déposer le matériau** | CTRL + Glisser&amp;Déposer | ⌘+Glisser&amp;Déposer | Maintenez cette touche enfoncée tout en faisant glisser un matériau (ou un matériau adaptable) dans le viewport pour n’affecter qu’une partie spécifique du modèle 3D. |
|  |  |  |  |
| **Contrainte/contraint Manipulateur** | Changement | Changement | Contraignez la transformation lors du réglage du manipulateur (translation ou rotation) dans vue 3D. Conserver le rapport lors du réglage du manipulateur dans vue 2D. |

# Aberration latérale

![](../../assets/v12_post_aberration.jpg)

Simule l’aberration chromatique en décalant les couches de couleur vers l’extérieur à partir du centre de l’image, reproduisant les franges de couleur visibles sur les bords des objectifs d’appareil photo réels.

| <b>Paramètre</b> | <b>Description</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Quantité</b> | Contrôle l’intensité de l’effet de frange des couleurs. Plus la valeur est élevée, plus la séparation des canaux vers les bords est prononcée. |
| <b>Rayon</b> | Contrôle la taille de la zone centrale non affectée. Des valeurs faibles rapprochent l’effet d’aberration du centre et affectent une plus grande partie de l’image. |
| <b>Lissage</b> | Contrôle le smoothness de la transition entre le centre corrigé et les bords aberrants. |
| <b>Rapport</b> | Définit le rapport L/H de la zone affectée. Une valeur de 1 crée une forme circulaire ; les valeurs supérieures à 1 créent un motif elliptique plus large. |
| <b>Centrer X</b> | Position horizontale du centre optique à partir duquel l&#39;aberration rayonne. |
| <b>Centrer Y</b> | Position verticale du centre optique à partir duquel l&#39;aberration rayonne. |
| <b>Aberrations achromatiques</b> | Remplace les couleurs d’aberration de l’arc-en-ciel standard par des tons verts/violets. |

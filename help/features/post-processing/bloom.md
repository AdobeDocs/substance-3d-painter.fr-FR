# Flou lumineux

![](../../assets/v12_post_bloom.jpg)

Crée une lueur douce autour des zones lumineuses de la scène. Simule la dispersion de la lumière dans une aura lumineuse.

| <b>Paramètre</b> | <b>Description</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Quantité</b> | Contrôle l’intensité de l’effet d’épanouissement. Des valeurs élevées produisent une lueur plus prononcée autour des zones claires. |
| <b>Seuil</b> | Définit le niveau de luminosité minimum requis pour déclencher l’effet de floraison. Seuls les pixels plus lumineux que cette valeur sont éclaircis. Un seuil de 1,0 signifie que seuls les pixels plus lumineux que le blanc de l’écran fleuriront. |
| <b>Atténuation</b> | Détermine l’étendue de la propagation de la tache à partir des zones lumineuses. Les valeurs faibles créent une lueur plus compacte, tandis que les valeurs élevées répartissent l’effet sur une plus grande zone. |

# Post-traitement

![](../../assets/v12_banner_post_effects2.jpg)

Les effets postérieurs sont des filtres qui peuvent être appliqués aux images rendues dans la fenêtre d’affichage de Substance 3D Painter pour simuler des effets de caméra courants.

Les effets postérieurs peuvent être activés dans n&#39;importe quel projet via la fenêtre [Paramètres d&#39;affichage](../../interface/display-settings/display-settings.md).

>[!NOTE]
>
> Ces effets de post-traitement ne sont pas appliqués à la vue 2D par commodité. Seule la vue 3D affiche le résultat de l’image avec les effets.

Les pages suivantes décrivent les différents effets post-traitement actuellement pris en charge :

* [Profondeur de champ](depth-of-field.md)
* [Flou lumineux](bloom.md)
* [Reflet](glare.md)
* [Halo](lens-flare.md)
* [Aberration latérale](lateral-aberration.md)
* [Vignette](vignette.md)
* [Accentuer](sharpen.md)
* [Grain de film](film-grain.md)
* [Mappage de tons](tone-mapping.md)
* [Correction colorimétrique](color-correction.md)

La table de texture de référence peut également être utilisée pour affiner le résultat final de l’image. Pour plus d&#39;informations, consultez la documentation sur le [profil colorimétrique](color-profile.md).

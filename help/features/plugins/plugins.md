# Plugins

Substance 3D Painter dispose d’une API de script dédiée qui permet de créer des plug-ins personnalisés pour ajouter des fonctionnalités et un comportement personnalisés.\
Les modules sont écrits en JavaScript et peuvent être combinés avec le langage XML pour créer une interface personnalisée dans l’application. Pour plus de détails sur les éléments disponibles dans l’API, consultez la documentation sur les scripts (disponible à partir du menu Aide de l’application).

## Plug-ins par défaut

Substance 3D Painter dispose de deux plug-ins par défaut présentant des différences.

* [Enregistrement automatique](autosave.md)

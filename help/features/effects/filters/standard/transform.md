## Description

Le Transforme est utilisé pour transformer (mettre à l’échelle, faire pivoter, décaler) un calque.

Il est utilisé sur un calque de texture ou à l&#39;intérieur d&#39;un masque (sortie noir et blanc) pour par example transformer des motifs, des formes etc.

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Mode de répétition :</b> | Sélectionnez le mode de répétition. |
| <b>Mode symétrie :</b> | Sélectionnez le mode de retournement. |
| <b>Mise à l&#39;échelle X:</b> | Réglez l’échelle X du résultat. |
| <b>Mise à l&#39;échelle Y:</b> | Réglez l’échelle Y du résultat. |
| <b>Décalage X :</b> | Ajustez le décalage X du résultat. |
| <b>Décalage Y:</b> | Ajustez le décalage sur Y du résultat. |
| <b>Rotation de mosaïque sécurisée :</b> | Activez/désactivez la rotation de sécurité des vignettes. |
| <b>Rotation :</b> | Réglez la rotation. |
| <b>Mise à l&#39;échelle :</b> | Réglez la mise à l’échelle globale. |
| <b>Décalage :</b> | Ajustez le décalage global. |

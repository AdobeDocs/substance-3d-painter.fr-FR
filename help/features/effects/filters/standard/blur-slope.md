# Pente du flou

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="./Resources/icon_blur_slope.png" alt="Icône Pente de flou" title="Pente du flou"/><br><strong>Entrée :</strong> effets/flou, niveaux de gris</td>
    <td style="border: 0;" valign="top">Description<br>Le filtre Flou de Pente crée un effet de maculage ou de fondu, particulièrement visible sur les contours très contrastés entre les couleurs.<br>Il est utilisé soit directement sur un calque de texture pour flouter des matériaux entiers ou des textures spécifiques, soit sur un masque pour étaler le masque. Il peut entraîner des effets tels que des ébréchures ou des altérations des bords, une fuite de dirt ou une rouille maculée.</td>
  </tr>

## Entrées

| Saisir un nom | Description |
| --- | --- |
| **Bruit personnalisé :** niveaux de gris | Utilisez une texture personnalisée ou un point d’ancrage comme bruit personnalisé. |

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| **Valeur initiale :** | Attribuez une valeur aléatoire pour créer une variation différente sans modifier les paramètres généraux. |
| **Intensité :** | Réglez l’intensité du flou. |
| **Diviseur d&#39;intensité :** | Sélectionnez la répartition de l’intensité du flou. |
| **Mode de fusion :** | Sélectionnez le mode de fusion utilisé par le flou de pente. |
| **Qualité :** | Réglez la qualité de l’effet. |

### Paramètres de la source

| Nom du paramètre | Description |
| --- | --- |
| **Type de source :** | Indiquez si la source utilise le bruit par défaut, l’entrée précédente ou un bruit personnalisé. |
| **Flou :** | Réglez l’intensité du flou du bruit ou de l’entrée source. |
| **Position :** | Réglez le milieu du bruit source ou de l’entrée, comme pour une commande de luminosité. |
| **Contraste :** | Réglez le contraste du bruit ou de l’entrée source. |
| **Remplissage source :** | Ajustez la répétition du bruit ou de l’entrée source. |

## Description

Le filtre Flou peut être utilisé pour flouter des cartes ou des masques.

Il est utilisé soit directement sur un calque de texture pour, par exemple, flouter des matériaux entiers ou des textures spécifiques. Il peut également être utilisé sur les masques.

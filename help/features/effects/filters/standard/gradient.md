## Description

Le filtre Dégradé remappe les valeurs de niveaux de gris d’une image à l’aide d’un dégradé personnalisé.

Il peut être utilisé pour ajuster les valeurs d’une image en niveaux de gris ou pour colorer une entrée en niveaux de gris en la mappant à un dégradé personnalisé.

</td>
</tr>
</table>

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Afficher le dégradé (débogage) :</b> | Activez/désactivez l’affichage du débogage de dégradé. |
| <b>Quantité de couleur :</b> | Réglez le nombre de couleurs utilisées dans le dégradé. |
| <b>Couleur de Fusion en linéaire :</b> | Activez le mélange linéaire des couleurs. |
| <b>Couleur 1:</b> | Sélectionnez la première couleur. |
| <b>Position de la couleur 1 :</b> | Ajustez la position de la première couleur. |
| <b>Couleur 2:</b> | Sélectionnez la deuxième couleur. |
| <b>Position de la couleur 2 :</b> | Réglez la position de la deuxième couleur. |
| <b>Couleur N:</b> | Sélectionnez la N ième couleur. |
| <b>Position de la couleur N :</b> | Ajustez la position de la nième couleur. |

### Transformation d&#39;entrée

<table>
<tr>
<td><b>Mode Niveaux de gris :</b></td>
<td>Sélectionnez le mode de transformation Niveaux de gris. Vous pouvez choisir entre Désaturation, Luminance, Moyenne, Max et Min.</td>
</tr>
<tr>
<td><b>Intensité du flou :</b></td>
<td>Réglez le degré de flou de l’entrée.</td>
</tr>
<tr>
<td><b>Balance :</b></td>
<td>Réglez la balance de l’entrée en déplaçant le point médian vers le noir ou le blanc, comme pour une commande de luminosité.</td>
</tr>
<tr>
<td><b>Contraste :</b></td>
<td>Réglez le contraste de l’entrée.</td>
</tr>
<tr>
<td><b>Inverser :</b></td>
<td>Activez/désactivez l’inversion des couleurs d’entrée.</td>
</tr>
</table>

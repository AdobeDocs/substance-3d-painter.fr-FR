## Description

Le filtre Correction colorimétrique permet de régler les modifications des tons clairs, moyens et foncés.

Il est utilisé sur un calque de remplissage pour effectuer des réglages subtils de contraste, de luminosité et de saturation.

## Paramètres

### Ombres

| Nom du paramètre | Description |
| --- | --- |
| **Contraste :** | Réglez le contraste des ombres. |
| **Luminosité :** | Réglez la luminosité des ombres. |
| **Saturation :** | Réglez la saturation des ombres. |

### Tons moyens

| Nom du paramètre | Description |
| --- | --- |
| **Contraste :** | Réglez le contraste des tons moyens. |
| **Luminosité :** | Réglez la luminosité des tons moyens. |
| **Saturation :** | Réglez la saturation des tons moyens. |

### Tons clairs

| Nom du paramètre | Description |
| --- | --- |
| **Contraste :** | Réglez le contraste des hautes lumières. |
| **Luminosité :** | Réglez la luminosité des hautes lumières. |
| **Saturation :** | Réglez la saturation des hautes lumières. |

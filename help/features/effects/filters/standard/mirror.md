## Description

Le filtre Miroir est un filtre de symétrie permettant de copier une partie de l’entrée.

Il est utilisé sur un calque de texture (couleur) ou un masque pour refléter des matériaux, masques, formes, etc. complets en fonction de l’axe de miroir.

</td>
</tr>
</table>

>[!NOTE]
>
> Le filtre miroir fonctionne dans l&#39;espace UV. Il peut donc être utile d&#39;ouvrir la Vue 2D dans le **Viewport**.

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Afficher le débogage :</b> | Active/désactive l&#39;affichage de la vue de débogage. |
| <b>Mode :</b> | Sélectionnez le mode miroir. |
| <b>Décalage Axe X :</b> | Réglez le décalage de l’axe X. |
| <b>Décalage Axe Y :</b> | Réglez le décalage de l’axe Y. |
| <b>Inverser l&#39;Axe X:</b> | Activez/désactivez l’inversion à l’axe X. |
| <b>Inverser l&#39;Axe Y:</b> | Activez l’inversion sur l’axe Y. |
| <b>Type d&#39;angle :</b> | Sélectionnez le mode de traitement des angles dupliqués. |

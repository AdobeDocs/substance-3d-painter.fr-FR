## Description

Le filtre Histogramme numérisé remappe le contraste et la luminosité d’une image en niveaux de gris d’entrée.

Il est utilisé soit directement sur un calque de remplissage, soit sur un masque (sortie noir et blanc) pour régler le contraste et la luminosité.

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Position :</b> | Réglez la position de l’histogramme. |
| <b>Contraste :</b> | Réglez le contraste/la baisse du résultat. |
| <b>Inverser la position :</b> | Activez/désactivez l’inversion de la position. A des valeurs de position très élevées ou très basses, cela inverse efficacement la sortie. |

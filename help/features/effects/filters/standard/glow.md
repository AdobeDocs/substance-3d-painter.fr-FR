## Description

Le filtre Lueur crée une lueur externe autour des parties visibles de l’entrée.

Il est utilisé sur un calque de texture ou à l’intérieur d’un masque (sortie noir et blanc) pour ajouter une lueur douce ou précise autour des formes et des matériaux.

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Utilisé sur un masque :</b> | Indique si la lueur est utilisée sur un masque. |
| <b>Mode :</b> | Indiquez si la lueur utilise le mode tamisé ou précis. |
| <b>Largeur :</b> | Réglez la largeur de la lueur. |
| <b>Planche :</b> | Réglez la propagation de la lueur. |
| <b>Opacité :</b> | Réglez l’opacité du rayonnement. |
| <b>Couleur :</b> | Réglez la couleur de la lueur. |

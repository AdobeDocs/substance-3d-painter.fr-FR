## Description

Le filtre Flou est un filtre très simple pour flouter des cartes ou des masques dans une direction spécifique.

Il est utilisé soit directement sur un calque de texture pour, par exemple, flouter des matériaux entiers ou des textures spécifiques. Il peut également être utilisé sur un masque pour flouter un masque.

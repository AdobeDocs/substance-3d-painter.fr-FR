# Conversion en niveaux de gris

<b>Entrée :</b> effets/couleur, désaturation, min, max

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Description

Le filtre Conversion en niveaux de gris convertit une image couche/couleur en niveaux de gris en pesant la luminance de chaque couche de couleur. Vous disposez de nombreuses options pour modifier la conversion.

Il est utilisé sur un calque de texture ou un calque de masque pour convertir les couches en niveaux de gris ou pour convertir une image couleur en niveaux de gris et l’utiliser comme masque.

## Entrées

| Saisir un nom | Description |
| --- | --- |
| <b>Entrée personnalisée :</b> couleur | Utilisez une texture personnalisée ou un point d’ancrage. |

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Entrée de canal :</b> | Sélectionnez l’entrée de canal utilisée pour la conversion. |
| <b>Inverser :</b> | Activez/désactivez l’inversion du résultat. |
| <b>Balance :</b> | Réglez la balance du résultat entre noir et blanc, comme pour un réglage de la luminosité. |
| <b>Contraste :</b> | Réglez le contraste/la baisse du résultat. |
| <b>Mode :</b> | Sélectionnez le mode de conversion des niveaux de gris. |
| <b>Rouge:</b> | Ajustez la pondération de la couche rouge. Cette pondération est utilisée pour calculer le résultat en niveaux de gris. |
| <b>Vert :</b> | Ajustez la pondération de la couche verte. Cette pondération est utilisée pour calculer le résultat en niveaux de gris. |
| <b>Bleu :</b> | Ajustez la pondération de la couche bleue. Cette pondération est utilisée pour calculer le résultat en niveaux de gris. |
| <b>Alpha :</b> | Ajustez la pondération du Canal Alpha. Cette pondération est utilisée pour calculer le résultat en niveaux de gris. |

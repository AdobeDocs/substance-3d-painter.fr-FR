## Description

Le filtre FXAA (anticrénelage) applique un filtre anticrénelage basé sur l’algorithme FXAA. Vous pouvez l’utiliser pour corriger les bords dentelés et pixellisés des formes.

Il est utilisé sur un calque de texture ou un calque de masque (sortie noir et blanc) pour rendre les contours contrastés nets moins irréguliers.

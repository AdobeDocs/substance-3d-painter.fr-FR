## Description

Le filtre Balance des couleurs apporte des modifications subtiles aux hautes lumières, aux tons moyens et aux ombres.

Il est utilisé sur un calque de remplissage pour effectuer des réglages de couleur subtils.

## Paramètres

### Tons clairs

| Nom du paramètre | Description |
| --- | --- |
| **Cyan &lt;-> Rouge :** | Déplacez la couleur vers le cyan ou le rouge. |
| **Magenta &lt;-> Vert :** | Déplacez la couleur vers le magenta ou le vert. |
| **Jaune &lt;-> Bleu :** | Déplacez la couleur vers le jaune ou le bleu. |

### Tons moyens

| Nom du paramètre | Description |
| --- | --- |
| **Cyan &lt;-> Rouge :** | Déplacez la couleur vers le cyan ou le rouge. |
| **Magenta &lt;-> Vert :** | Déplacez la couleur vers le magenta ou le vert. |
| **Jaune &lt;-> Bleu :** | Déplacez la couleur vers le jaune ou le bleu. |

### Ombres

| Nom du paramètre | Description |

## Description

Le filtre Perception TSL permet de régler la teinte, la saturation et la luminosité.

Il est utilisé sur un calque de texture (couleur) pour régler la teinte, la saturation et la luminosité.

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Mode :</b> | Sélectionnez le mode de réglage TSL. L&#39;option **Perception** ajuste les valeurs en fonction de notre perception des couleurs, tandis que l&#39;option **Normal** ajuste les valeurs en fonction de la façon dont l&#39;ordinateur représente les couleurs en interne. |
| <b>Teinte :</b> | Réglez la teinte. |
| <b>Saturation :</b> | Réglez la saturation. |
| <b>Luminosité :</b> | Réglez la luminosité. |

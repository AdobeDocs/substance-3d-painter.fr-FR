## Description

Le filtre Pixellisation convertit une entrée en gros blocs pour simuler un aspect pixellisé.

Il est utilisé sur un calque de texture (couleur) ou un masque pour pixelliser des matériaux, bruits, masques, formes complets, etc.

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Quantité De Pixels :</b> | Ajustez le nombre de pixels, ce qui a pour effet secondaire de modifier la taille des pixels. Plus le nombre de pixels est élevé, plus le nombre de pixels est petit. |
| <b>Appliquer À L&#39;Alpha :</b> | Indique si le filtre modifie également le Canal Alpha. |

## Description

Le filtre Dégradé dynamique remappe les valeurs de niveaux de gris d’une image à un dégradé défini par des couleurs placées à des points spécifiques le long du dégradé.

Il est utilisé sur un calque de texture ou à l’intérieur d’un masque (sortie noir et blanc) pour remapper les valeurs de niveaux de gris avec un dégradé échantillonné à partir d’une autre image.

| --- | --- |

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Orientation du dégradé :</b> | Indiquez si la source de dégradé est échantillonnée horizontalement ou verticalement. |
| <b>Position d&#39;entrée de dégradé :</b> | Réglez la position échantillonnée à partir de l’entrée de dégradé. |

## Description

Le filtre Passe-haut exécute un effet Passe-haut similaire à l’action Photoshop portant le même nom. Il est utile pour supprimer les grandes différences de luminance dans les images, comme lors du nettoyage des textures pour la répétition.

Il est utilisé sur un calque de texture ou un calque de masque pour supprimer les grandes différences de luminance.

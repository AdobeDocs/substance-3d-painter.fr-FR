## Description

Le filtre MatFinish Rough fait partie d’une collection de finitions métalliques et est utilisé pour créer un effet de métal brut.

Il est utilisé sur un calque de remplissage. Réglez la couleur, la rugosité, la métallique et d&#39;autres propriétés du calque de remplissage de base, puis ajoutez-le pour le traitement de surface final.

## Entrées

| Saisir un nom | Description |
| --- | --- |
| <b>Usure/salissures personnalisée :</b> niveaux de gris | Utilisez une texture d’usure/salissures personnalisée ou un point d’ancrage. |
| <b>Position :</b> Couleur | Utilisez le mappage de position baké. |
| <b>Normales des espaces monde :</b> couleur | Utilisez le mappage de Normales des espaces monde baké. |

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Valeur initiale :</b> | Attribuez une valeur aléatoire pour créer une variation différente sans modifier les paramètres généraux. |
| <b>Échelle :</b> | Ajustez l&#39;échelle globale de la finition. |
| <b>Usure/salissures d&#39;échelle :</b> | Réglez l’échelle du motif d’usure/salissures. |
| <b>Intensité du pinceau :</b> | Réglez l’intensité de l’effet de pinceau. |
| <b>Déformation du pinceau :</b> | Ajustez la quantité de déformation appliquée au pinceau. |
| <b>Utiliser un flocon personnalisé :</b> | Activez/désactivez l’utilisation de l’entrée Flocon personnalisée. |
| <b>Mappage triplanaire :</b> | Activez/désactivez le mappage triplanaire. |
| <b>Utiliser l&#39;Usure/salissures personnalisée :</b> | Activez/désactivez l’utilisation d’une texture d’usure/salissures personnalisée. |

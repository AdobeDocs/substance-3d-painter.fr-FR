## Description

Le filtre MatFinish Hammered fait partie d’une collection de finitions métalliques et est utilisé pour créer un effet de métal martelé.

Il est utilisé sur un calque de remplissage. Réglez la couleur, la rugosité, la métallique et d&#39;autres propriétés du calque de remplissage de base, puis ajoutez-le pour le traitement de surface final.

## Paramètres

| Nom du paramètre | Description |

| <b>Intensité des détails :</b> | Réglez l’intensité des détails de la surface. |

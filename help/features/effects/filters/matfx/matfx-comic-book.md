## Description

Le filtre BD MatFX stylise les matériaux avec un style inspiré des bandes dessinées.

Il est utilisé sur les calques de texture pour créer un style de rendu graphique et illustré avec un ombrage simplifié et un traitement visuel audacieux.

</td>
</tr>

## Entrées

| Saisir un nom | Description |
| --- | --- |
| <b>Ambient occlusion :</b> niveaux de gris | Utilisez le mappage d’ambient occlusion baké. |
| <b>Courbure :</b> niveaux de gris | Utilisez la map curvature bakée. |

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Type d&#39;entrée :</b> | Sélectionnez le type d’entrée utilisé par l’effet. |
| <b>Contraste d&#39;entrée :</b> | Réglez le contraste de l’entrée. |
| <b>Luminosité d&#39;entrée :</b> | Réglez la luminosité de l’entrée. |
| <b>Intensité des couleurs :</b> | Réglez l’intensité du traitement des couleurs. |
| <b>Opacité de la bordure :</b> | Réglez l’opacité des bordures. |
| <b>Tolérance de bordure :</b> | Réglez la tolérance de détection des bordures. |
| <b>Smoothness de bordure :</b> | Ajustez le smoothness des bordures. |
| <b>Intensité de la Peinture :</b> | Réglez l’intensité de l’effet peinture. |
| <b>Déformation :</b> | Réglez l’effet de déformation. |
| <b>Netteté :</b> | Réglez la netteté du résultat. |
| <b>Contraste de sortie :</b> | Réglez le contraste de la sortie. |
| <b>Luminosité de sortie :</b> | Réglez la luminosité de la sortie. |

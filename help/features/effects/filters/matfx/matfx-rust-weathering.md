## Description

Le filtre d’Altération de Rouille MatFX permet de créer une accumulation et une altération de rouille dans un matériau.

Il est utilisé sur les couches de texture ou les piles de matériau pour ajouter des effets de corrosion, de gouttes et d&#39;altération vieillie.

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Intensité du flou :</b> | Ajuste la force de l’effet de flou. |
| <b>Habillage flou :</b> | Active ou désactive l’habillage du flou. Lorsque l’habillage de flou est dessus, il échantillonne les pixels du côté opposé de la texture. |
| <b>Répartition des Rouilles :</b> | Réglez l’étalement de la rouille. |
| <b>Répartition du Smoothness :</b> | Réglez le smoothness d’étalement. |
| <b>Échelle des dommages du vernis :</b> | Réglez l’échelle des dommages du vernis. |
| <b>Intensité des gouttes :</b> | Réglez l’intensité des gouttes. |
| <b>Quantité D&#39;Échantillons Gouttes :</b> | Réglez la quantité d’échantillons de gouttes. |
| <b>Smoothness gouttes :</b> | Réglez le smoothness des gouttes. |

### Fusion

| Nom du paramètre | Description |
| --- | --- |
| <b>Intensité normale :</b> | Réglez l’intensité du mélange de maps normal. |
| <b>Intensité de l&#39;Ambient occlusion :</b> | Réglez l’intensité de fusion de la map AO. |
| <b>Intensité de l&#39;Height :</b> | Réglez l’intensité du mélange de maps height. |

**Métallique rugosité**

| Nom du paramètre | Description |
| --- | --- |
| <b>Intensité de la Base color :</b> | Réglez l’intensité de la base color. |
| <b>Intensité de la Rugosité :</b> | Réglez l’intensité du mélange de rugosités. |
| <b>Intensité Métallique :</b> | Réglez l&#39;intensité du mélange de cartes métallique. |

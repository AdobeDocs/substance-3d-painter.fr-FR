## Description

Le filtre Biseau ajoute un bord biseauté aux formes et masques en niveaux de gris.

Il est utilisé sur un calque de texture ou à l’intérieur d’un masque (sortie noir et blanc) pour créer un relief biseauté le long des contours d’une forme.

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Biseautage :</b> | Activez/désactivez l’habillage pour que les mosaïques biseautées soient horizontales et verticales. |
| <b>Distance :</b> | Réglez la taille du biseau. |
| <b>Type d&#39;angle :</b> | Indiquez si les coins de biseau sont arrondis ou angulars. |
| <b>Lissage :</b> | Ajustez la quantité de lissage appliquée au biseau. Sans aucun lissage, les biseaux courbes peuvent présenter des stries visibles en raison du crénelage le long de la courbe. |
| <b>Mode flou :</b> | Indiquez si le biseau utilise un flou uniforme ou non uniforme. Le flou non uniforme concentre l’effet de flou sur les zones biseautées, ce qui peut aider à conserver les détails, mais le flou uniforme est plus uniforme. |

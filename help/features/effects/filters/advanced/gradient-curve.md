## Description

Le filtre Courbe de dégradé remappe les valeurs via une courbe de dégradé personnalisable.

Il est utilisé sur un calque de texture ou à l’intérieur d’un masque (sortie noir et blanc) pour remapper les valeurs de niveaux de gris avec des formes de courbes prédéfinies.

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Paramètre prédéfini :</b> | Sélectionnez le paramètre prédéfini de courbe. |
| <b>Inverser :</b> | Activez/désactivez l’inversion du résultat. |
| <b>Balance :</b> | Réglez la balance du résultat entre noir et blanc, comme pour un réglage de la luminosité. |
| <b>Contraste :</b> | Réglez le contraste ou l’atténuation du résultat. |

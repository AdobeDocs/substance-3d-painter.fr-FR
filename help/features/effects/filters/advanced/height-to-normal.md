## Description

Le filtre Height à la normale génère des données normales précises en fonction du canal d’height.

Il est utilisé sur un calque de texture pour convertir les informations d’height en données ordinaires.

</td>
</tr>

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Écraser la normale existante :</b> | Activez/désactivez le remplacement des données normales existantes. |
| <b>Utiliser les unités universelles :</b> | Activez/désactivez l’utilisation des unités universelles pour la conversion. |
| <b>Intensité normale :</b> | Si **Utiliser les unités universelles** est **Faux**, utilisez-le pour ajuster l&#39;intensité des données normales générées. |
| <b>Taille de la surface (cm) :</b> | Si l&#39;option **Utiliser les unités universelles** a la valeur **Vrai**, utilisez-la pour ajuster la largeur ou l&#39;height de la surface représentée, selon la valeur la plus élevée. |
| <b>Profondeur Height (cm) :</b> | Si l&#39;option **Utiliser les unités universelles** est **True**, utilisez-la pour ajuster la plage d&#39;heights maximale de la surface. |

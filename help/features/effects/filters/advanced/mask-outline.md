## Description

Le filtre Contour du masque crée un contour à partir des bords d’un masque.

Il est utilisé sur un calque de texture ou à l’intérieur d’un masque (sortie noir et blanc) pour générer un contour intérieur, extérieur ou double autour d’une forme masquée.

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Position du masque :</b> | Indiquez si le contour doit apparaître à l’extérieur, à l’intérieur ou des deux côtés du bord du masque. |
| <b>Commencer À Partir Du Noir :</b> | Indique si le contour doit commencer en noir. Cela agit efficacement comme une sorte de bascule d&#39;inversion. |
| <b>Seuil :</b> | Ajustez le seuil utilisé pour détecter le bord du masque. |
| <b>Largeur :</b> | Ajustez la largeur du contour. |
| <b>Flou :</b> | Ajustez le flou appliqué au contour. |
| <b>Forme de courbe :</b> | Ajustez la forme de l’atténuation du contour. |

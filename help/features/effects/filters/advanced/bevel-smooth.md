## Description

Le filtre Bevel smooth dessine un dégradé à partir des bords d’un masque vers l’extérieur, l’intérieur ou les deux.

Il est utilisé sur un calque de texture ou à l’intérieur d’un masque (sortie noir et blanc) pour créer un dégradé biseauté lisse à partir des contours d’un masque.

## Entrées

| Saisir un nom | Description |
| --- | --- |
| <b>Map distance :</b> niveaux de gris | Utilisez une texture personnalisée ou un point d’ancrage. |

<a name="parameters"></a>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| <b>Direction :</b> | Sélectionnez le côté de la bordure du masque qui doit être dilaté. |
| <b>Distance :</b> | Ajustez la distance de dilatation du biseau. |
| <b>Lissage :</b> | Réglez l’intensité du lissage appliqué au masque. |
| <b>Décalage de courbe :</b> | Ajustez les bordures du masque vers l’intérieur ou vers l’extérieur. |
| <b>Forme de courbe :</b> | Indiquez si la pente en biseau utilise une courbe pincée ou arrondie. |
| <b>Seuil de masque :</b> | Réglez la valeur utilisée pour détecter les bordures du masque à partir de l’entrée. |
| <b>Multiplicateur de Map distance :</b> | Ajustez l&#39;impact de la Map distance sur la distance maximale. |
| <b>Biseautage :</b> | Indique si le biseau est affiché en mosaïque horizontale et verticale. |

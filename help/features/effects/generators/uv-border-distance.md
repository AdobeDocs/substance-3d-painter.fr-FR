# Distance de la bordure UV

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_border_distance.png" alt=""/><br><strong>Entrée :</strong> filet, uv, distance</td>
    <td style="border: 0;" valign="top"><strong>Description</strong><br>Le générateur de distance de la bordure UV crée un masque en niveaux de gris sur les bordures des Îlots UV, ce qui vous permet d’ajouter facilement divers effets qui suivent les bordures de vos UV.<br><br>Le générateur de distance de la bordure UV produit une texture monochrome (noir et blanc). Par conséquent, il est utile pour générer un masque qui met en évidence les zones proches de vos bordures UV.</td>
  </tr>
</table>

## Paramètres

| Nom du paramètre | Description |
| --- | --- |
| **Inverser** | Inversez la sortie du générateur. |
| **Balance** | Réglez la balance de l’effet en déplaçant le point médian vers le noir ou le blanc comme une commande de luminosité. |
| **Contraste** | Réglez le contraste/l’atténuation de l’effet. |
| **Smoothness** | Réglez l’arrondi de l’effet. Ceci est particulièrement visible lorsqu&#39;une valeur de **Smoothness** faible est utilisée. |
| **Distance** | Ajustez l’éloignement de l’effet par rapport aux bordures UV. |

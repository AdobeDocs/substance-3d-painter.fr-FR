# Vérificateur UV

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>Entrée :</strong> uv, bordure, aléatoire</td>
    <td style="border: 0;" valign="top"><strong>Description</strong><br>Le générateur de damier UV applique un motif de damier de type grille à votre modèle afin que vous puissiez facilement repérer les problèmes UV tels que l’étirement, l’échelle irrégulière ou la distorsion. <br><br>Le générateur de correcteur UV est généralement utilisé directement sur une couche de remplissage pour voir les distorsions UV.</td>
  </tr>
</table>

## Paramètres

<table>
  <tr>
    <th>Nom du paramètre</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><strong>Seed</strong></td>
    <td>Définissez la valeur de départ utilisée pour générer la texture dirt. <br><ul><li>Cliquez sur Aléatoire pour passer à une autre valeur de départ aléatoire.</li><li>Cliquez sur le crayon pour afficher la valeur de départ actuelle, puis entrez une valeur spécifique si nécessaire.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Mode colorimétrique du vérificateur</strong></td>
    <td>Sélectionnez le mode d’attribution des couleurs :<br><ul><li><strong>Uniforme</strong> : applique la même couleur sur l'ensemble de textures.</li><li><strong>Aléatoire</strong> : applique une couleur aléatoire à chaque Îlot UV.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Couleur du damier</strong></td>
    <td>Définissez la couleur du motif en damier.</td>
  </tr>
  <tr>
    <td><strong>Mosaïque en damier</strong></td>
    <td>Ajustez la taille du motif en damier.</td>
  </tr>
  <tr>
    <td><strong>Opacité de la grille de contrôle</strong></td>
    <td>Réglez l’opacité de la grille. Avec une opacité de 0, seule une texture en damier est visible, sans grille.</td>
  </tr>
  <tr>
    <td><strong>Couleur des bordures UV</strong></td>
    <td>Définissez la couleur des bordures UV.</td>
  </tr>
  <tr>
    <td><strong>Largeur des bordures UV</strong></td>
    <td>Ajustez la largeur des bordures UV.</td>
  </tr>
</table>

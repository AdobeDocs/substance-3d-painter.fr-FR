# Vérificateur UV

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>Entrée :</strong> uv, bordure, aléatoire</td>
    <td style="border: 0;" valign="top"><strong>Description</strong><br>Le générateur de vérificateur d'UV applique un motif de vérification de type grille à votre modèle afin que vous puissiez facilement repérer les problèmes d'UV tels que le étiré, l'échelle irrégulière ou la distorsion. <br><br>Le générateur UV Checker est généralement utilisé directement sur un calque de remplissage pour voir les UV.</td>
  </tr>
</table>

## Paramètres

<table>
  <tr>
    <th>Nom du paramètre</th>
    <th>Description</th>
  </tr>
  <tr>
    <td><strong>Seed</strong></td>
    <td>Définissez la valeur de départ utilisée pour générer la texture de dirt. <br><ul><li>Cliquez sur Aléatoire pour passer à une autre valeur de départ aléatoire.</li><li>Cliquez sur le crayon pour afficher la valeur de départ actuelle, puis entrez une valeur spécifique si nécessaire.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Mode colorimétrique du vérificateur</strong></td>
    <td>Sélectionnez le mode d’attribution des couleurs :<br><ul><li><strong>Uniforme</strong> : applique la même couleur sur tout le jeu de textures.</li><li><strong>Aléatoire</strong> : applique une couleur aléatoire à chaque Îlot UV.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Couleur du damier</strong></td>
    <td>Définissez la couleur du motif en damier.</td>
  </tr>
  <tr>
    <td><strong>Mosaïque de Grille en damier</strong></td>
    <td>Ajustez la taille du motif en damier.</td>
  </tr>
  <tr>
    <td><strong>Opacité de la Grille du correcteur</strong></td>
    <td>Réglez l’opacité de la grille. Avec une opacité de 0, seule une texture de vérification est visible, sans grille.</td>
  </tr>
  <tr>
    <td><strong>Couleur des bordures d’UV</strong></td>
    <td>Définissez la couleur des bordures de l’UV.</td>
  </tr>
  <tr>
    <td><strong>Largeur des bordures d’UV</strong></td>
    <td>Ajustez la largeur des bordures de l’UV.</td>
  </tr>
</table>

# Générateurs

Les générateurs sont des substances qui génèrent un masque ou des textures en fonction de la topologie de maillage [à l&#39;aide de cartes d&#39;utilité ancrées telles que Position, Courbure et Normale de l&#39;espace universel](../../baking/baking.md).

>[!NOTE]
>
> La plupart des générateurs produisent des textures monochromes (noir et blanc), ce qui les rend particulièrement utiles pour créer des masques qui contrôlent un calque Matériau. Cependant, rien ne vous empêche d’utiliser un générateur monochrome comme calque de remplissage ou un générateur de couleurs complètes comme masque.

Pour ajouter un générateur à un masque :

1. Dans le **panneau Calques**, cliquez avec le bouton droit de la souris sur le masque.
1. Sélectionnez **Ajouter un générateur**.
1. Lorsque le masque est sélectionné, le générateur apparaît sous le calque dans le **panneau Calques**.
1. Le générateur étant sélectionné, dans le panneau **Propriétés**, cliquez sur le bouton **Générateur** pour sélectionner le générateur spécifique à appliquer.

Pour ajouter un générateur à un calque :

1. Cliquez avec le bouton droit sur le calque.
1. Sélectionnez **Ajouter un générateur**.
1. Le générateur apparaît sous le calque dans le **panneau Calques**.
1. Le générateur étant sélectionné, dans le panneau **Propriétés**, cliquez sur le bouton **Générateur** pour sélectionner le générateur spécifique à appliquer.

>[!NOTE]
>
> Il est possible d’appliquer des générateurs, des filtres ou d’autres effets à un calque donné ou à son masque. Lorsque vous sélectionnez un calque, ses effets sont visibles sous le calque. Pour voir les effets appliqués au masque, sélectionnez le masque plutôt que seulement le calque.

![](../../assets/generators/generator_spectrum.png)

Chaque générateur dispose d’un ensemble de paramètres vous permettant d’affiner le masque obtenu.\
Pour ajouter des générateurs personnalisés dans le tiroir, voir : [Ajout de contenu au tiroir](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/spdoc/adding-content-to-the-shelf-142213317.html)

>[!NOTE]
>
> Lors de la création d&#39;une substance dans Substance 3D Designer, vous pouvez choisir le **modèle Painter Generator** pour obtenir un bon point de départ pour votre nouveau générateur.

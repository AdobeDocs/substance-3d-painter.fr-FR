# Envoyer vers

![Image de bannière](../assets/sendto_banner.jpg)

<b>Envoyer à</b> sont des actions permettant d&#39;exporter et d&#39;importer facilement des ressources d&#39;un projet vers une autre application, ce qui évite d&#39;avoir à le faire manuellement. Envoyer vers peut être utilisé pour exporter le modèle 3D et ses textures vers une autre application de rendu, ou pour recevoir des matériaux de Substance de Substance 3D Designer.

Les actions Envoyer vers sont disponibles via le menu <b>Fichier > Envoyer</b> à.

Les <b>Envoyer à</b> actuellement pris en charge sont les suivants :

* Envoyer vers <b>Photoshop</b>
* Envoyer vers <b>Substance 3D Stager</b>
* Envoyer vers <b>After Effects</b>

Painter peut également recevoir des ressources d’autres applications, telles que :

* <b>Substance 3D Designer</b>
* <b>Substance 3D Sampler</b>

Pour plus d&#39;informations sur la réception des ressources, consultez la [page de documentation dédiée](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md).

>[!NOTE]
>
> Certains workflows Envoyer vers sont uniquement disponibles avec la version Adobe de Painter en raison de dépendances techniques avec le logiciel Creative Cloud Desktop.
> 
> En outre, certaines actions du menu Envoyer vers peuvent ne pas être disponibles si le logiciel requis n’est pas installé.

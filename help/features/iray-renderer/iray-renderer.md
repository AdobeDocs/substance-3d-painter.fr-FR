# Moteur de rendu Iray

![](../../assets/iray-mode.jpg){width="600px"}

**Iray** est un système de rendu par tracé accéléré par GPU développé par [Nvidia](http://www.nvidia.com/object/nvidia-iray.html).\
Avec Iray, il est possible de créer une image avec une grande précision d&#39;éclairage dans la scène et en haute définition (grande résolution).

## Mode Iray

Pour démarrer l’Iray, le mode de Substance 3D Painter doit être modifié.\
Pour ce faire, appuyez de différentes manières :

* En appuyant sur la touche **F10** (ou sur **F9** pour revenir au mode Peinture)
* En cliquant sur l&#39;icône Caméra dans la barre d&#39;outils principale
* En utilisant le menu Mode

## Paramètres d&#39;Iray

Iray utilise un ensemble spécifique de paramètres, mais également des propriétés communes partagées par le viewport normal de Substance 3D Painter.

* [Paramètres d’Iray](iray-settings.md)
* [Paramètres de la visionneuse et de MDL](viewer-and-mdl-settings.md)

## Paramètres d&#39;affichage

Les paramètres Affichage vous permettent de contrôler les paramètres caméra et effets de post-traitement.\
Ils sont identiques au rendu viewport normal, ce qui leur permet d’être synchronisés et d’éviter les différences d’éclairage indésirables.

Pour plus d&#39;informations, consultez la page dédiée : [Paramètres d&#39;affichage](../../interface/display-settings/display-settings.md)

# Tuiles UV

![](../../assets/banner-uvtiles.jpg)

Les tuiles UV permettent de mettre en texture plusieurs ensembles de textures, sur plusieurs UV, à l’intérieur d’un Jeu de textures.

Par défaut, avec un workflow traditionnel, une texture est répétée sur chaque plage d’UV. Avec les Tuiles UV, chaque plage devient une texture dédiée. Ce workflow permet d’augmenter virtuellement la résolution générale de la texture en divisant les UV en plusieurs ensembles de textures. Actuellement, les tuiles UV prennent uniquement en charge la convention de dénomination des UDIM.

Pour en savoir plus sur le workflow de Tuile UV, consultez les pages suivantes :

* [Création de projet](../../getting-started/project-creation.md) avec le workflow de Tuile UV.
* Affichage des Tuiles UV dans la [Vue 2D](../../interface/viewport/2d-view.md).
* [Masque de Tuile UV](../../interface/layer-stack/geometry-mask.md) pour améliorer les performances.
* Importation et utilisation de [séquences d&#39;images](image-sequence.md).
* Ajustement de la résolution par Tuile UV dans les [paramètres de Jeu de textures](../../interface/texture-set/texture-set-settings.md).

>[!NOTE]
>
> Travailler avec des projets de Tuile UV peut être exigeant, nous vous recommandons d&#39;utiliser un SSD pour améliorer les temps de chargement et les performances générales. Nous vous recommandons également de définir l’emplacement du cache sur un disque SSD.

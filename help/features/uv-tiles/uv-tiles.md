# Tuiles UV

![](../../assets/banner-uvtiles.jpg)

Les tuiles UV permettent de texturer plusieurs ensembles de textures, dans plusieurs plages UV, à l’intérieur d’un ensemble de textures.

Par défaut, avec un workflow traditionnel, une texture est répétée sur chaque plage d’UV. Avec les tuiles UV, chaque gamme devient une texture dédiée. Ce workflow permet d’augmenter virtuellement la résolution générale de la texture en divisant les UV en plusieurs ensembles de textures. Les tuiles UV ne prennent actuellement en charge que la convention de dénomination UDIM.

Pour en savoir plus sur le workflow Mosaïque UV, consultez les pages suivantes :

* [Création de projet](../../getting-started/project-creation.md) avec le workflow de mosaïque UV.
* Affichage des carreaux UV dans la [vue 2D](../../interface/viewport/2d-view.md).
* [Masque de tuile UV](../../interface/layer-stack/geometry-mask.md) pour améliorer les performances.
* Importation et utilisation de [séquences d&#39;images](image-sequence.md).
* Ajuster la résolution par carreaux UV dans les [paramètres du jeu de textures](../../interface/texture-set/texture-set-settings.md).

>[!NOTE]
>
> Travailler avec des projets UV Tile peut être exigeant, nous vous recommandons d&#39;utiliser un SSD pour améliorer les temps de chargement et les performances générales. Nous vous recommandons également de définir l’emplacement du cache sur un disque SSD.
